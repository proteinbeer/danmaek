디스코드는 음성 채팅이나 메시지 확인 때문에 자주 쓰는 프로그램입니다. 다만 컴퓨터를 켤 때마다 자동으로 함께 열리면 편할 때도 있지만, 꼭 필요하지 않은 날에는 먼저 꺼야 해서 오히려 번거롭게 느껴질 수 있습니다.

저도 어느 순간부터 윈도우를 켜면 디스코드가 자동으로 실행되는 것이 조금 귀찮아졌습니다. 처음에는 작업 표시줄 쪽에 떠 있는 아이콘만 보고 원인을 잘 몰랐는데, 실제 설정을 열어보니 자동 실행과 시스템 트레이 최소화가 같이 얽혀 있었습니다.

결론부터 말하면 디스코드 사용자 설정의 시스템, 일반 메뉴에서 자동 실행을 바로 끌 수 있습니다. X 버튼을 눌러도 완전히 종료되지 않는 경우는 시스템 트레이 최소화 설정도 같이 확인하는 편이 좋았습니다.

## 1. 시스템 메뉴 찾기

디스코드 왼쪽 아래에서 사용자 설정으로 들어간 뒤 검색창에 시스템을 입력했습니다.

검색 결과에서 시스템이 바로 보였고, 그 아래 일반 메뉴로 들어가면 자동 실행 관련 옵션을 확인할 수 있었습니다. 메뉴가 익숙하지 않다면 항목을 하나씩 찾는 것보다 검색창을 쓰는 편이 훨씬 빠릅니다.

특히 디스코드는 설정 항목이 꽤 많은 편이라 음성, 알림, 게임 관련 메뉴를 지나치다가 원하는 옵션을 놓치기 쉽습니다. 저처럼 자동 실행만 빨리 끄고 싶다면 검색창에 시스템만 입력해도 거의 바로 도착할 수 있습니다.

## 2. 컴퓨터를 켤 때 자동으로 Discord를 엽니다 끄기

시스템의 일반 화면으로 들어가면 가장 먼저 눈에 띄는 항목이 컴퓨터를 켤 때 자동으로 Discord를 엽니다입니다.

이 스위치를 끄면 윈도우를 시작할 때 디스코드가 자동으로 함께 실행되지 않습니다. 제가 원했던 것도 딱 이 부분이었고, 별도의 저장 버튼 없이 스위치를 바꾸는 순간 바로 적용됐습니다.

바로 아래에는 Discord를 최소화된 상태로 실행하기 같은 비슷한 항목도 보입니다. 이름이 비슷해서 헷갈릴 수 있지만, 자동 실행 자체를 끄려면 가장 위의 컴퓨터를 켤 때 자동으로 Discord를 엽니다를 먼저 보면 됩니다.

자동 실행을 유지한 채 시작할 때 창만 덜 거슬리게 하고 싶다면 최소화 실행을 조절하는 방식이 맞고, 저처럼 아예 시작과 함께 열리지 않게 하고 싶다면 맨 위 스위치를 끄는 것이 핵심입니다.

## 3. X를 눌러도 계속 남는다면 시스템 트레이 설정 확인

자동 실행을 껐는데도 디스코드가 계속 살아 있는 것처럼 느껴질 때가 있습니다.

이럴 때는 같은 화면에 있는 Discord를 시스템 트레이에 최소화하세요 설정을 함께 볼 필요가 있습니다. 이 옵션이 켜져 있으면 창 오른쪽 위의 X를 눌러도 프로그램이 완전히 종료되지 않고 작업 표시줄 오른쪽 알림 영역 쪽으로 최소화될 수 있습니다.

그래서 사용자는 분명 창을 닫았다고 생각했는데, 나중에 보니 디스코드가 이미 켜져 있는 것처럼 느낄 수 있습니다. 자동 실행 문제와 완전 종료 문제를 따로 구분해서 보면 헷갈림이 줄어듭니다.

제 경우에도 처음에는 자동 실행 때문인지, 창 닫기 동작 때문인지 구분이 잘 안 됐습니다. 설정 화면을 같이 보니 왜 디스코드가 자꾸 남아 있었는지 이해하기 쉬웠습니다.

## 4. 작업 관리자에서 디스코드가 실행 중인지 확인

설정을 바꾼 뒤에도 디스코드가 이미 실행 중인지 궁금할 때는 작업 관리자에서 확인할 수 있습니다.

작업 관리자 프로세스 목록에서 Discord 항목이 보이면 현재 프로세스가 돌아가고 있다는 뜻입니다. 이 화면은 자동 실행을 끄는 메뉴는 아니지만, 지금 디스코드가 백그라운드에서 남아 있는지 확인할 때는 도움이 됩니다.

특히 자동 실행을 껐는데도 이미 한 번 실행된 상태라면, 변경 직후 바로 사라지지 않고 현재 세션에서는 계속 보일 수 있습니다. 이럴 때는 재부팅 후 다시 확인해보거나, 현재 실행 중인 디스코드를 직접 종료한 뒤 동작을 보는 편이 정확합니다.

작업 관리자 화면에서는 다른 프로그램이 많이 보여 복잡해 보일 수 있는데, 디스코드 항목만 확인하시면 됩니다. 이번 이미지는 다른 앱 이름을 가려서 디스코드만 보이게 정리해 두었습니다.

디스코드가 컴퓨터를 켤 때마다 자동으로 열려 불편했다면 사용자 설정의 시스템, 일반 메뉴부터 보시면 됩니다.

핵심은 컴퓨터를 켤 때 자동으로 Discord를 엽니다를 끄는 것이고, 창을 닫아도 프로그램이 남아 있다면 시스템 트레이 최소화 설정까지 같이 확인하는 것입니다. 제 경우에는 이 두 항목을 구분해서 보고 나서야 왜 디스코드가 자꾸 떠 있는지 깔끔하게 정리됐습니다.
