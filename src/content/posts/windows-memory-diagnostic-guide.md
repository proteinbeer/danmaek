게임이 갑자기 종료되거나 블루스크린이 반복되면 RAM을 의심하게 됩니다. 하지만 프로그램 하나가 튕겼다는 이유만으로 메모리 불량이라고 결론 내릴 수는 없습니다. 드라이버, 오버클럭, 저장장치 오류 등도 비슷한 증상을 만들 수 있기 때문입니다.

Windows에는 별도 프로그램을 설치하지 않고 RAM을 검사할 수 있는 Windows 메모리 진단 도구가 있습니다. 검사 결과까지 직접 확인하면 부품을 교체하기 전에 실제 근거 하나를 확보할 수 있습니다.

## 1. 검사 전에 하던 작업부터 저장합니다

Windows 메모리 진단은 PC를 재시작한 뒤 검사를 진행합니다. 열어둔 문서나 작업을 먼저 저장합니다.

Windows 키 + R을 눌러 실행 창을 열고 mdsched를 입력합니다. Windows 메모리 진단 창에서 \'지금 다시 시작하여 문제 확인\'을 선택할 수 있습니다. 바로 재부팅하기 곤란하다면 다음 부팅 때 검사하는 옵션을 사용합니다.

## 2. 기본 검사부터 실행합니다

재부팅하면 진단 화면이 나타나고 검사가 자동으로 시작됩니다. 처음에는 기본 설정으로 실행해도 됩니다. 검사가 끝나면 PC가 다시 시작됩니다.

표준 검사에서 문제가 없는데 RAM 관련 증상이 계속된다면 검사 화면에서 F1을 눌러 확장 검사를 선택할 수도 있습니다. 확장 검사는 더 오래 걸리므로 처음부터 무조건 사용할 필요는 없습니다.

## 3. 결과 알림을 놓쳤다면

로그인 후 Windows가 결과를 알림으로 표시할 수 있습니다. 알림을 못 봤다면 다시 검사할 필요 없이 이벤트 뷰어에서 MemoryDiagnostics-Results 관련 로그를 확인할 수 있습니다.

오류가 발견되지 않았다면 해당 검사에서 메모리 오류가 검출되지 않았다는 뜻입니다. 이것을 PC의 모든 하드웨어가 정상이라는 의미로 확대해서 해석하면 안 됩니다.

## 4. 오류가 발견되면 바로 RAM을 버려야 할까

오류가 검출됐다면 현재 RAM 설정도 확인합니다. BIOS에서 XMP나 EXPO 같은 메모리 프로필 또는 수동 오버클럭을 사용한다면 기본 설정에서도 같은 오류가 발생하는지 비교할 수 있습니다.

RAM이 여러 개라면 모듈 또는 슬롯 하나와 관련된 문제인지 분리 테스트할 수도 있습니다. 부품을 다룰 때는 PC 전원을 완전히 끄고 전원 연결을 분리합니다. 완제품 PC의 보증 조건이 걸려 있거나 탈착에 익숙하지 않다면 제조사 안내를 우선합니다.

## 5. 오류 없음인데 블루스크린이 계속된다면

RAM 검사 하나만으로 블루스크린 원인을 확정할 수 없습니다. 메모리 진단에서 이상이 없는데 특정 게임에서만 종료된다면 그래픽 드라이버나 게임 자체를 확인할 수 있습니다. 반대로 프로그램 종류와 관계없이 블루스크린이 반복되고 메모리 오류까지 검출된다면 RAM과 메모리 설정을 더 우선적으로 조사할 근거가 생깁니다.

이 검사의 목적은 증상만 보고 \'RAM이 범인\'이라고 찍는 것이 아닙니다. Windows 메모리 진단 → 결과 확인 → 오류가 있으면 기본 메모리 설정에서도 재현되는지 확인 → 필요하면 모듈과 슬롯을 분리해 검사하는 식으로 범위를 좁히는 데 의미가 있습니다.
