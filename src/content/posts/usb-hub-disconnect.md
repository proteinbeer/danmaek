USB 허브는 포트 하나를 여러 개로 늘려주기 때문에 주변기기가 많은 책상에서 매우 편합니다.

하지만 외장 SSD, 웹캠, 캡처보드, 마이크를 한꺼번에 연결한 뒤 장치가 랜덤하게 끊기기 시작하는 경우도 있죠.

이때 허브 포트가 불량이라고 단정하기 전에 전력 공급과 데이터 대역폭을 따로 봐야 합니다.

포트가 여덟 개 있다고 여덟 장치를 모두 최대 성능으로 쓸 수 있다는 뜻은 아닙니다.

## 1. 버스파워 허브의 한계

전원 어댑터가 없는 USB 허브는 PC의 USB 포트에서 전력을 받아 연결된 장치에 나눠줍니다.

키보드와 마우스처럼 소비전력이 낮은 장치 몇 개는 큰 문제가 없지만, 저장장치와 조명 장치가 늘어나면 여유가 줄어듭니다.

전력이 부족하면 장치가 완전히 꺼졌다 다시 연결되거나 파일 복사 중 외장 저장장치가 사라질 수 있습니다.

웹캠이 갑자기 멈추고 마이크가 다시 잡히는 식으로 서로 다른 증상이 동시에 생기기도 하죠.

## 2. 셀프파워 허브가 필요한 경우

별도 전원 어댑터를 사용하는 셀프파워 허브는 연결 장치에 더 안정적으로 전력을 공급할 수 있습니다.

외장 저장장치 여러 개나 고해상도 웹캠, 캡처보드를 함께 쓰신다면 이런 제품이 더 적합한 경우가 많습니다.

다만 전원 어댑터가 있다고 데이터 속도까지 자동으로 빨라지는 것은 아닙니다.

전력 문제와 대역폭 문제는 서로 다른 제한이기 때문에 두 가지를 따로 확인해야 합니다.

## 3. 모든 포트가 같은 대역폭을 나눠 쓴다

허브의 여러 포트는 결국 PC와 연결된 하나의 상위 USB 연결을 공유합니다.

외장 SSD 두 개가 동시에 대용량 파일을 전송하고 4K 웹캠과 캡처보드까지 데이터를 보내면 병목이 생길 수 있죠.

장치가 끊기지 않더라도 속도가 예상보다 낮거나 영상 프레임이 떨어질 수 있습니다.

허브 제품 설명에서 상위 연결 규격과 포트별 지원 속도를 확인하시는 것이 중요합니다.

## 4. 충전 포트와 데이터 포트 구분

일부 허브에는 충전 전용 포트가 따로 있습니다.

여기에 저장장치나 마우스를 연결하면 전원은 들어오지만 PC에서 장치가 인식되지 않을 수 있습니다.

반대로 데이터 포트가 높은 충전 출력을 지원하지 않는 제품도 있습니다.

포트 옆 표시와 설명서를 보고 각 포트 역할을 구분하시는 편이 좋습니다.

USB C 허브는 노트북 충전 전원을 통과시키는 전원 공급 입력을 따로 가진 경우도 있습니다.

이 포트에 외장 SSD를 꽂아도 데이터가 연결되지 않는 경우가 있으니 모양만 보고 사용하시면 안 됩니다.

## 5. 케이블이 병목일 수도 있다

허브와 PC를 연결하는 케이블이 분리형이라면 케이블 규격도 전체 성능에 영향을 줍니다.

고속 허브에 충전용 저속 케이블을 사용하면 포트 사양을 제대로 살리지 못할 수 있습니다.

케이블 길이가 지나치게 길거나 단자가 느슨하면 장치 연결이 반복될 수도 있습니다.

문제 확인 단계에서는 허브 기본 케이블을 사용하고 연장 케이블은 빼는 편이 좋습니다.

## 6. 끊기는 장치부터 직접 연결

외장 SSD가 끊긴다면 먼저 그 장치 하나만 PC 본체에 직접 연결해보시면 됩니다.

직접 연결에서는 정상이라면 저장장치 고장보다 허브의 전력이나 대역폭 문제에 무게가 실립니다.

그다음 허브에 장치를 하나씩 다시 추가하면 어느 시점부터 문제가 생기는지 확인할 수 있습니다.

한 번에 모두 연결한 상태에서 원인을 찾는 것보다 훨씬 빠른 방법입니다.

## 7. 포트 수보다 구성

USB 허브를 고를 때 포트 개수가 많으면 좋아 보이지만 실제로는 내가 무엇을 연결할지가 더 중요합니다.

키보드와 마우스 위주라면 간단한 허브로 충분하지만 저장장치와 영상 장비가 많다면 전원과 대역폭이 우선입니다.

제가 허브를 구성한다면 외장 SSD와 캡처보드처럼 데이터가 많은 장치는 PC에 직접 연결하고, 키보드와 마우스 같은 저부하 장치를 허브에 묶겠습니다.

한 포트에 모든 것을 몰아넣기보다 역할을 나누는 것이 가장 안정적입니다.

## 8. 장치마다 우선순위를 나눌 것

키보드와 마우스는 데이터 사용량이 작지만 입력이 끊기면 체감이 바로 큽니다.

외장 SSD와 캡처보드는 데이터량이 많아 다른 장치와 대역폭을 나눠 쓸 때 성능 저하가 눈에 띄죠.

허브 하나에 모든 장치를 몰기보다 끊기면 곤란한 장치와 대역폭을 많이 쓰는 장치를 본체 포트로 분산하시면 됩니다.

포트 개수보다 연결 구조를 설계하는 것이 안정성에는 더 중요합니다.

허브가 지나치게 뜨거워지는지도 살펴보시면 됩니다.

고속 데이터 전송과 충전을 동시에 오래 하면 작은 허브 내부 온도가 올라가고, 품질이 낮은 제품은 이때 연결 안정성이 더 나빠질 수 있습니다.

책상 뒤에 열이 갇히는 곳보다 공기가 통하는 위치에 두는 편이 좋습니다.

손을 대기 어려울 정도로 과열된다면 연결 장치 수를 줄이고 제품 상태를 확인하셔야 합니다.
