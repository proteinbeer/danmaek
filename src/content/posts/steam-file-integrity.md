게임이 갑자기 튕기거나 텍스처가 깨지고 실행 파일을 찾지 못한다는 오류가 나오면 가장 먼저 재설치를 떠올리기 쉽습니다.

하지만 수십 기가바이트를 다시 받기 전에 스팀의 게임 파일 무결성 검사를 먼저 돌리는 편이 훨씬 효율적이죠.

무결성 검사는 설치된 파일을 스팀 서버의 정상 파일과 비교해서 빠졌거나 손상된 부분만 다시 내려받는 기능입니다.

전체 게임을 지우는 방식이 아니라 필요한 파일만 복구하기 때문에 문제 원인이 파일 손상이라면 시간을 크게 줄일 수 있습니다.

## 1. 무결성 검사가 필요한 증상

게임을 실행했는데 로고에서 꺼지거나 특정 맵에 들어갈 때만 튕긴다면 설치 파일 일부가 손상됐을 가능성이 있습니다.

업데이트 도중 컴퓨터가 꺼졌거나 저장장치 오류가 있었던 뒤 문제가 시작됐다면 더 먼저 확인할 항목입니다.

모드나 사용자 파일을 넣은 뒤 이상해진 경우에도 기본 파일 복구에 도움이 됩니다.

다만 게임 자체 설정 파일이나 세이브 파일까지 원래 상태로 되돌리는 기능은 아니므로 무엇을 고치는 기능인지 구분하시는 것이 중요합니다.

## 2. 검사하는 가장 빠른 경로

스팀 라이브러리에서 문제가 있는 게임을 선택한 뒤 톱니바퀴 메뉴나 마우스 오른쪽 버튼을 이용해 속성으로 들어갑니다.

설치된 파일 항목에서 게임 파일 무결성 검사를 실행하면 스팀이 설치된 파일을 차례대로 확인합니다.

게임 용량과 저장장치 속도에 따라 시간이 달라질 수 있습니다.

검사 중에는 같은 저장장치에서 대용량 복사나 다른 게임 검사를 동시에 하지 않는 편이 안정적이죠.

## 3. 한두 개 파일이 실패해도 이상하지 않은 경우

검사가 끝난 뒤 한 개 또는 몇 개 파일을 확인하지 못했다는 메시지가 나오는 경우가 있습니다.

이 문구만 보고 설치가 완전히 망가졌다고 판단할 필요는 없습니다.

일부 게임은 실행할 때마다 바뀌는 로컬 설정 파일을 따로 사용합니다.

스팀도 이런 파일은 검증 과정에서 다르게 보일 수 있다고 안내하므로, 검사 뒤 게임이 정상 실행되는지가 더 중요합니다.

## 4. 모드 사용 중이라면 먼저 백업

무결성 검사는 스팀이 제공하는 정상 파일과 다른 기본 파일을 다시 받을 수 있습니다.

게임 파일을 직접 수정하는 모드를 사용하셨다면 일부 변경 내용이 사라질 수 있죠.

창작마당처럼 스팀이 별도로 관리하는 모드와 게임 폴더에 직접 덮어쓴 모드는 성격이 다릅니다.

후자의 경우에는 수정 파일을 따로 백업한 뒤 검사를 진행하는 편이 안전합니다.

## 5. 검사 뒤에도 실행이 안 될 때

무결성 검사를 마쳤는데도 같은 문제가 반복된다면 파일 손상만이 원인이 아닐 가능성이 큽니다.

그래픽 드라이버, 윈도우 업데이트, 보안 프로그램, 오버레이 프로그램, 필수 실행 구성 요소 같은 쪽으로 범위를 넓혀야 합니다.

특히 게임이 예전에는 됐는데 업데이트 직후부터 안 된다면 게임 자체 패치 문제일 수도 있습니다.

이때 무조건 윈도우를 초기화하기보다 해당 게임 커뮤니티에서 같은 버전의 공통 증상이 있는지 확인하는 편이 빠릅니다.

## 6. 재설치보다 먼저 해야 하는 이유

재설치는 확실해 보이지만 원인이 파일 손상이 아니라면 시간만 오래 걸리고 결과는 같을 수 있습니다.

무결성 검사는 설치 상태를 짧은 시간 안에 확인하면서 손상된 파일만 다시 받는다는 점에서 첫 번째 점검으로 가치가 큽니다.

저는 스팀 게임 문제가 생기면 재부팅, 무결성 검사, 드라이버와 업데이트 확인 순서로 보는 편이 합리적이라고 봅니다.

게임 하나가 안 된다고 수백 기가바이트 라이브러리부터 건드리는 것보다 작은 범위부터 확인하는 편이 결국 가장 빠르죠.

## 7. 실제 점검은 증상 하나를 기준으로

무결성 검사를 하기 전에는 문제가 언제 생기는지 한 번 기억해두는 편이 좋습니다. 게임을 켜자마자 꺼지는지, 특정 맵에 들어갈 때만 튕기는지, 업데이트 직후부터 시작됐는지에 따라 검사 뒤 다음에 볼 항목이 달라집니다.

검사 뒤 같은 장면에서 문제가 사라졌다면 파일 손상 가능성이 높았다고 볼 수 있습니다. 반대로 아무 변화가 없다면 같은 검사를 반복하기보다 그래픽 드라이버와 모드, 백그라운드 프로그램, 게임 자체 패치 상태로 넘어가야 합니다.

특정 파일이 매번 다시 받아진다면 보안 프로그램이 그 파일을 지우거나 게임 실행 시 자동으로 변경하는 구조인지도 확인할 필요가 있습니다. 검사 횟수가 많다고 해결 확률이 계속 올라가는 것은 아니죠.

가장 중요한 건 무결성 검사를 해결책 하나가 아니라 원인을 나누는 검사로 보는 것입니다. 통과했다면 파일 문제 가능성을 줄였다는 뜻이고, 문제가 발견됐다면 재설치 전에 필요한 부분만 복구했다는 뜻입니다. 이렇게 한 단계씩 범위를 좁히면 게임 하나 때문에 PC 전체 설정을 건드리는 일을 줄일 수 있습니다.
