브라우저, 메신저, 문서, 게임까지 한 화면에 쌓이면 프로그램보다 창을 찾는 데 시간이 더 걸릴 때가 있습니다.

윈도우 11의 가상 데스크톱을 사용하면 프로그램을 종료하지 않고 작업 공간 자체를 여러 개로 나눌 수 있습니다.

모니터를 여러 대 연결하는 기능과는 다릅니다.

같은 화면 안에서 업무용 공간, 개인용 공간, 회의용 공간처럼 데스크톱을 전환하는 방식입니다.

## 1. 작업 보기에서 새 공간 만들기

작업표시줄의 작업 보기 버튼을 누르거나 윈도우 키와 탭 키을 누르면 현재 열린 창과 데스크톱 목록이 나타납니다.

여기서 새 데스크톱을 선택하면 빈 작업 공간을 하나 더 만들 수 있습니다.

새 데스크톱을 만든다고 프로그램이 새로 설치되거나 사용자 계정이 바뀌는 것은 아닙니다.

같은 윈도우 계정 안에서 창을 나눠서 보여주는 기능입니다.

예를 들어 첫 번째 데스크톱에는 업무 브라우저와 문서를 두고 두 번째에는 음악과 개인 메신저를 둘 수 있습니다.

창을 최소화하고 다시 찾는 과정이 줄어드는 것이 핵심입니다.

## 2. 데스크톱 이름을 정해두기

가상 데스크톱은 이름을 바꿀 수 있습니다.

업무, 게임, 회의처럼 목적이 보이는 이름으로 정해두면 여러 공간을 만들었을 때 헷갈리지 않습니다.

배경화면도 데스크톱별로 다르게 지정할 수 있습니다.

색이나 사진을 다르게 두면 지금 어느 공간에 있는지 눈으로 바로 구분하기 쉬워집니다.

공간을 많이 만드는 것보다 역할이 명확한 두세 개를 유지하는 편이 실용적입니다.

정리가 목적이었는데 데스크톱 자체가 너무 많아지면 다시 찾는 일이 생기기 때문입니다.

## 3. 열린 창을 다른 데스크톱으로 이동

작업 보기에서 열린 창을 원하는 데스크톱으로 옮길 수 있습니다.

잘못된 공간에서 실행했다고 프로그램을 종료하고 다시 열 필요가 없습니다.

회의 전에 개인 메신저나 게임 관련 창을 다른 데스크톱으로 옮기는 식으로 활용할 수도 있습니다.

화면 공유를 자주 하시는 분이라면 필요한 창만 모아둔 공간을 하나 만드는 것도 꽤 편합니다.

다만 가상 데스크톱이 보안 기능은 아닙니다.

다른 데스크톱에 옮겼다고 파일이나 프로그램이 잠기는 것은 아니므로 다른 사람이 PC를 사용한다면 별도 계정을 만드는 편이 맞습니다.

## 4. 빠르게 전환하는 습관

작업 보기 화면을 매번 열어도 되지만 익숙해지면 키보드로 전환하는 편이 빠릅니다.

윈도우 키와 컨트롤 키를 누른 상태에서 좌우 방향키를 사용하면 데스크톱 사이를 이동할 수 있습니다.

가상 데스크톱을 자주 쓰는 분에게는 이 전환 방식이 핵심입니다.

마우스로 창을 최소화하고 아이콘을 다시 찾는 것보다 작업 공간 전체를 좌우로 넘기는 감각에 가깝습니다.

처음에는 낯설지만 하루 정도만 의식해서 사용하면 익숙해집니다.

특히 노트북 한 화면으로 여러 종류의 일을 동시에 하실 때 효과가 더 큽니다.

## 5. 멀티태스킹보다 정리 기능에 가깝다

가상 데스크톱을 쓴다고 CPU나 메모리가 줄어드는 것은 아닙니다.

여러 공간에서 프로그램을 많이 열면 실제 자원 사용량은 그대로 늘어납니다.

이 기능의 장점은 성능 향상이 아니라 시야를 정리하는 데 있습니다.

필요한 창만 보이게 만들면 지금 하고 있는 일에 집중하기 쉬워지고 실수로 다른 창을 클릭하는 일도 줄어듭니다.

저는 가상 데스크톱을 멀티태스킹 기능보다 한 화면을 여러 책상처럼 쓰는 기능이라고 보는 편이 이해하기 쉽다고 생각합니다.

모니터를 추가할 공간이 없거나 노트북 하나로 일하신다면 비용 없이 작업 공간을 넓히는 가장 간단한 방법 중 하나입니다.

## 6. 데스크톱을 닫아도 프로그램은 바로 사라지지 않는다

가상 데스크톱 하나를 닫는다고 그 안에 열려 있던 프로그램이 강제로 종료되는 것은 아닙니다.

열린 창은 남아 있는 다른 데스크톱으로 이동되기 때문에 실수로 공간을 닫았다고 작업이 모두 사라졌다고 생각할 필요는 없습니다.

다만 저장하지 않은 문서는 여전히 프로그램 자체의 저장 상태에 영향을 받습니다.

가상 데스크톱은 창 배치를 관리하는 기능이지 문서 자동 저장 기능이 아닙니다.

업무가 끝난 뒤 불필요한 데스크톱을 정리하면 다음 로그인에서도 작업 공간을 이해하기 쉬워집니다.

가상 공간은 많을수록 좋은 것이 아니라 현재 작업을 빠르게 구분할 수 있을 정도가 가장 효율적입니다.
