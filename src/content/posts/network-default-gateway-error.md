Windows 문제 해결 후 잠깐 인터넷이 돌아왔다가 다시 끊기면서 ’기본
게이트웨이를 사용할 수 없음’이 반복될 수 있습니다. 기본 게이트웨이는
보통 PC가 인터넷으로 나갈 때 처음 만나는 공유기입니다.

## 끊기는 순간 공유기까지 ping이 되는지 봅니다

ipconfig로 기본 게이트웨이를 확인합니다. 주소가 192.168.0.1이라면
ping 192.168.0.1 -t를 실행해 연결을 계속 관찰합니다.

인터넷이 끊기는 순간 게이트웨이 ping도 실패한다면 PC와 공유기 사이의
유선·무선 연결, 랜카드, 공유기 LAN 쪽을 먼저 봅니다. 게이트웨이 ping은
계속 정상인데 인터넷만 실패한다면 공유기 바깥 WAN이나 DNS로 범위를 옮길
수 있습니다.

유선이면 정상 랜선과 다른 LAN 포트로 직접 비교합니다. 와이파이라면 같은
위치의 다른 기기는 정상인지 확인해 특정 PC 문제인지 무선망 전체 문제인지
나눕니다.

절전 후에만 반복된다면 장치 관리자의 랜카드 전원 관리와 드라이버 상태도
확인할 가치가 있습니다. 수동 IP를 사용한다면 기본 게이트웨이가 현재
공유기 주소와 일치하는지도 봅니다.

이 오류에서 가장 유용한 기준은 ’문제가 생긴 순간에도 기본 게이트웨이가
응답하는가’입니다. 이 한 가지 테스트로 PC↔공유기 구간과 그 바깥 문제를
먼저 나눌 수 있습니다.
