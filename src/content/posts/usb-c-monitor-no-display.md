노트북과 모니터에 USB C 단자가 있으니 케이블 하나만 연결하면 화면과 충전이 모두 될 것처럼 보입니다.

하지만 USB C는 단자 모양이 같아도 지원 기능이 크게 다르기 때문에 충전은 되는데 화면은 나오지 않는 상황이 흔합니다.

핵심은 노트북 USB C 포트가 영상 출력을 지원하는지, 케이블이 영상 신호를 전달할 수 있는지입니다.

모니터 불량을 의심하기 전에 이 두 가지를 먼저 확인하셔야 합니다.

## 1. USB C는 모양만 같을 뿐 기능이 다르다

USB C는 뒤집어 꽂을 수 있는 물리적인 단자 규격입니다.

그 단자가 데이터, 충전, 영상 출력을 모두 지원한다는 뜻은 아닙니다.

노트북의 USB C 포트가 디스플레이포트 대체 모드를 지원해야 모니터로 영상 신호를 보낼 수 있습니다.

충전 전용이나 데이터 전용 포트라면 같은 케이블을 꽂아도 화면은 나오지 않습니다.

포트 옆에 디스플레이포트나 번개 모양 표시가 있는지 확인하고, 가장 정확하게는 노트북 제조사 사양표를 보셔야 합니다.

아이콘이 없는 제품도 있어 외관만으로 판단하기 어려울 수 있습니다.

## 2. 케이블도 영상 지원이 필요

USB C 케이블이라고 모두 같은 기능을 지원하지 않습니다.

저가 충전 케이블은 전원 공급만 되고 고속 데이터와 영상 출력을 지원하지 않을 수 있죠.

스마트폰 충전에 잘 쓰던 케이블을 모니터에 연결했는데 충전만 된다면 케이블부터 의심할 만합니다.

모니터에 기본 제공된 USB C 케이블이 있다면 먼저 그 케이블로 테스트하시는 것이 좋습니다.

새 케이블을 구매하신다면 원하는 해상도와 주사율, 영상 출력 지원 여부를 제품 설명에서 확인하셔야 합니다.

단순히 최대 충전 전력만 보고 고르면 화면 연결에는 적합하지 않을 수 있습니다.

## 3. 모니터 입력 선택 확인

HDMI와 디스플레이포트, USB C 입력을 모두 가진 모니터는 현재 입력 소스를 직접 선택해야 하는 경우가 있습니다.

케이블을 USB C에 꽂았는데 모니터가 여전히 HDMI 입력을 보고 있다면 신호 없음이 표시될 수 있죠.

모니터 메뉴에서 USB C나 타입 C 입력을 선택해보시면 됩니다.

자동 입력 감지를 지원하는 제품도 있지만 여러 기기가 연결돼 있으면 원하는 입력으로 바로 전환되지 않을 수 있습니다.

## 4. 충전 전력과 화면 출력은 별개

화면이 잘 나오는데 노트북 충전 속도가 느린 반대 상황도 있습니다.

이 경우 모니터의 USB 전원 공급 출력이 노트북이 요구하는 전력보다 낮을 수 있습니다.

가벼운 노트북은 65W 정도로 충분한 경우가 많지만 고성능 노트북은 더 높은 전력을 요구할 수 있습니다.

전력이 부족하면 충전 중이라고 표시되면서도 게임이나 고부하 작업에서 배터리가 서서히 줄 수 있죠.

영상 출력이 된다는 사실과 노트북을 최대 속도로 충전할 수 있다는 사실은 따로 확인하셔야 합니다.

USB C 하나로 모든 기능을 합칠수록 각 기능의 지원 범위를 더 꼼꼼히 봐야 합니다.

## 5. 도킹 장치와 변환기 제거

USB C 허브나 도킹 장치를 거쳐 모니터를 연결했다면 문제 확인 단계에서는 노트북과 모니터를 직접 연결해보시는 편이 좋습니다.

허브가 특정 해상도나 주사율을 지원하지 않거나 영상 대역폭을 다른 포트와 나눠 쓸 수 있기 때문입니다.

직접 연결에서는 화면이 나오는데 허브를 거치면 안 된다면 모니터보다 허브 사양을 봐야 합니다.

특히 여러 모니터와 외장 SSD를 동시에 쓰는 도킹 환경에서는 전체 대역폭 제한이 쉽게 드러납니다.

## 6. 가장 빠른 확인 순서

노트북 포트의 영상 출력 지원 여부, 모니터 입력 선택, 모니터 기본 케이블, 직접 연결 순서로 확인하시면 됩니다.

이 네 단계만으로 USB C 화면 미출력 문제의 상당 부분을 구분할 수 있습니다.

USB C는 케이블 하나로 책상을 깔끔하게 만들 수 있는 좋은 규격입니다.

다만 단자 모양이 같다고 기능까지 같다고 생각하는 순간 가장 헷갈리는 주변기기 규격이 되기도 하죠.

## 7. 노트북을 바꾸면 같은 모니터도 달라진다

모니터와 케이블이 그대로인데 노트북만 바꿨더니 화면이 나오지 않는다면 새 노트북의 USB C 기능 차이를 먼저 봐야 합니다.

같은 제조사 제품이라도 모든 USB C 포트가 영상 출력을 지원하는 것은 아닙니다.

특히 얇은 노트북은 포트 수가 적어 하나의 단자에 충전과 영상, 데이터 역할이 몰리는 경우가 많습니다.

구매 전에 포트 개수보다 각 포트가 실제로 무엇을 지원하는지 보는 습관이 중요합니다.
