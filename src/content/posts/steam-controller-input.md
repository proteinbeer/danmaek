엑스박스 패드나 듀얼센스를 PC에 연결했는데 스팀 게임에서 버튼이 이상하게 나오거나 아예 인식하지 못하는 경우가 있습니다.

윈도우에서 장치가 보인다면 바로 드라이버를 다시 설치하기보다 스팀 입력 설정과 게임의 자체 패드 지원 방식을 먼저 확인하는 편이 좋습니다.

스팀 입력은 여러 종류의 컨트롤러 입력을 게임이 이해할 수 있는 형태로 바꿔주는 계층입니다.

덕분에 원래 특정 패드를 지원하지 않는 게임에서도 키를 다시 배치할 수 있지만, 게임의 자체 지원과 겹치면 이중 입력이 생기기도 하죠.

## 1. 윈도우에서 먼저 장치 확인

컨트롤러가 스팀 문제인지 PC 연결 문제인지 구분하려면 윈도우에서 장치가 정상 인식되는지부터 확인합니다.

USB로 연결했을 때는 되는데 블루투스에서만 안 된다면 스팀보다 무선 연결 문제를 먼저 보는 편이 맞습니다.

배터리가 부족하거나 오래된 케이블이 충전만 지원하고 데이터 연결을 못 하는 경우도 있습니다.

패드 문제는 소프트웨어로 보이지만 실제로는 케이블 하나가 원인인 경우도 꽤 많죠.

## 2. 스팀 컨트롤러 설정 확인

스팀 설정의 컨트롤러 항목에서는 연결된 장치와 기본 동작을 확인할 수 있습니다.

빅 픽처 모드에서도 컨트롤러 중심으로 설정을 확인하기 편합니다.

버튼 테스트에서 입력이 정상적으로 잡히는데 게임만 반응하지 않는다면 게임별 설정으로 범위를 좁힐 수 있습니다.

반대로 여기서부터 입력이 이상하다면 게임을 바꿔가며 테스트하기보다 연결과 장치 상태를 먼저 해결해야 합니다.

## 3. 스팀 입력을 켜야 좋은 게임과 꺼야 좋은 게임

오래된 게임이나 특정 패드를 직접 지원하지 않는 게임에서는 스팀 입력이 큰 도움이 됩니다.

키보드와 마우스 입력을 패드 버튼에 배치해 패드 지원이 없는 게임을 조작할 수도 있죠.

반대로 듀얼센스 기능을 게임이 직접 지원하는 경우에는 스팀 입력을 거치지 않아야 햅틱이나 적응형 트리거가 제대로 작동하는 사례도 있습니다.

게임별로 자체 지원 수준이 다르므로 무조건 켜기보다 한 게임씩 테스트하는 것이 중요합니다.

## 4. 버튼이 두 번 눌리는 이중 입력

버튼을 한 번 눌렀는데 메뉴가 두 칸 이동한다면 게임과 스팀이 같은 패드를 동시에 처리하고 있을 가능성이 있습니다.

외부 패드 변환 프로그램까지 함께 켜져 있다면 입력 경로가 하나 더 늘어납니다.

이럴 때는 변환 프로그램을 잠시 종료하고 스팀 입력을 켠 상태와 끈 상태를 각각 비교합니다.

입력 도구를 여러 개 겹쳐 쓰는 것보다 하나의 경로로 단순하게 만드는 것이 안정적입니다.

## 5. 게임별 레이아웃 활용

스팀 입력의 장점은 게임마다 다른 버튼 구성을 저장할 수 있다는 점입니다.

공식 레이아웃뿐 아니라 커뮤니티에서 만든 구성을 불러와 시작점으로 사용할 수도 있습니다.

다만 커뮤니티 레이아웃이 현재 게임 버전과 맞지 않을 수도 있습니다.

중요한 버튼이 빠져 있거나 업데이트 전 기준일 수 있으므로 적용한 뒤 기본 동작을 한 번씩 확인하시는 것이 좋습니다.

## 6. 패드 문제를 스팀 탓으로만 보면 안 된다

컨트롤러 인식은 윈도우, 연결 방식, 스팀 입력, 게임 자체 지원이 이어지는 구조입니다.

어느 한 단계만 보고 해결하려 하면 같은 설정을 반복해서 바꾸기 쉽습니다.

저는 윈도우 인식, 스팀 버튼 테스트, 게임별 스팀 입력 순서로 확인하는 방식을 추천합니다.

이 순서를 지키면 패드 자체 문제인지 설정 충돌인지 빠르게 나눌 수 있고 불필요한 드라이버 재설치도 줄어듭니다.

## 7. 무선과 유선을 번갈아 테스트

패드가 가끔 끊기거나 버튼 입력이 늦는다면 스팀 설정만 계속 바꾸기 전에 연결 방식도 비교해야 합니다. 블루투스에서는 문제가 있는데 USB에서는 정상이라면 게임이나 스팀 입력보다 무선 환경과 배터리, 블루투스 어댑터 쪽 가능성이 커집니다.

반대로 USB에서도 같은 버튼만 계속 이상하다면 패드 하드웨어 자체 문제를 의심할 수 있습니다. 스팀의 입력 테스트에서 같은 버튼이 여러 번 눌리거나 아예 잡히지 않는지 확인하면 게임별 문제와 장치 문제를 나누는 데 도움이 됩니다.

게임 하나에서만 아이콘이 엑스박스 버튼으로 보이는 것은 고장과 다른 문제입니다. 스팀 입력이 입력 방식을 변환하면서 게임이 엑스박스 계열 입력으로 인식하는 경우가 있기 때문입니다. 조작은 정상인데 아이콘만 다른 상황이라면 불필요하게 드라이버를 건드릴 필요는 없습니다.

결국 패드 문제는 연결, 스팀 입력, 게임 지원이라는 세 층을 나누어 보는 것이 핵심입니다. 한 층씩 확인하면 같은 설정을 반복해서 켰다 끄는 시간을 줄이고, 정말 필요한 곳만 바꿀 수 있습니다.
