PC를 켜면 Slack도 자동으로 실행되도록 해두고 사용하고 있습니다. 그런데 한동안 Windows에 로그인해도 Slack 창은 보이지 않고 오른쪽 아래 시스템 트레이에만 실행되어 있었습니다.

자동 실행 자체는 되고 있으니 오류는 아니었습니다. 문제는 저는 PC를 켜면 Slack부터 확인하는 편이라 매번 트레이 아이콘을 다시 눌러 창을 여는 과정이 귀찮았다는 점입니다.

처음에는 \'Windows 시작 프로그램에 Slack이 들어가 있는데 왜 창은 안 뜨지?\' 싶었는데, 자동 실행과 시작할 때 창을 표시하는 것은 별개의 설정이었습니다.

## 1. 자동 실행되는데 창이 안 뜨는 이유

Slack은 Windows 로그인 시 자동으로 실행하면서도 창을 화면에 표시하지 않고 시스템 트레이에 최소화된 상태로 시작할 수 있습니다.

Slack 공식 문서에도 Windows용 설정인 HideOnStartup이 따로 존재합니다. 로그인 시 실행이 활성화된 상태에서 Slack을 화면에 표시할지, 시스템 트레이에 최소화해서 시작할지를 제어하는 항목입니다.

즉 작업 관리자나 Windows 시작 앱 목록에서 Slack이 활성화되어 있다는 것만으로는 \'부팅 후 Slack 창까지 자동으로 열린다\'는 뜻이 아닙니다.

저도 Slack 자체는 이미 자동으로 실행되고 있었습니다. 바꾸고 싶었던 것은 자동 실행 여부가 아니라 시작했을 때 창이 보이는 방식이었습니다.

## 2. Slack에서 시작 설정을 바꿨습니다

Slack 데스크톱 앱의 환경설정에서 Windows 로그인 시 Slack을 실행하는 설정과 시작 시 앱을 숨길지에 관한 설정을 확인할 수 있습니다.

제가 원했던 동작은 간단했습니다.

Windows 로그인 → Slack 자동 실행 → 트레이에만 숨지 않고 Slack 창도 화면에 표시.

반대로 PC를 켰을 때 Slack이 자동으로 실행되기는 하되 당장 화면을 차지하는 것이 싫다면 트레이에 최소화해서 시작하는 방식이 더 편할 수 있습니다.

어느 쪽이 더 좋은 설정이라기보다 PC를 켠 직후 Slack을 확인하는지에 따라 선택하면 됩니다.

## 3. Windows 시작 앱과 Slack 설정은 역할이 조금 다릅니다

이 문제에서 헷갈리기 쉬운 부분이 있습니다.

Windows의 시작 앱 설정에서 Slack을 끄면 로그인할 때 Slack 자체가 자동으로 실행되지 않을 수 있습니다. 반면 Slack은 자동으로 실행되는데 창만 보이지 않는다면 시작 앱을 계속 켰다 껐다 하기보다 Slack의 시작 동작을 확인하는 편이 맞습니다.

증상을 나눠보면 쉽습니다.

PC를 켠 뒤 Slack 프로세스 자체가 실행되지 않는다 → 자동 실행 설정을 확인합니다.

Slack은 실행되어 있고 트레이 아이콘도 있는데 창만 안 보인다 → 시작 시 숨김 또는 최소화 관련 설정을 확인합니다.

제가 겪은 것은 두 번째였습니다.

## 4. 저는 창까지 열리게 두는 편이 더 편했습니다

Slack을 항상 확인하는 사람에게는 자동 실행되면서 트레이에만 숨어 있는 것이 오히려 한 단계 더 거쳐야 하는 설정이 될 수 있습니다.

저는 Windows를 시작한 뒤 어차피 Slack을 열어 확인하기 때문에 처음부터 창이 보이는 쪽으로 바꿨습니다. 사소한 차이지만 매번 트레이에서 Slack을 다시 찾지 않아도 돼서 이쪽이 제 사용 방식에는 더 맞았습니다.

반대로 Slack은 알림만 받다가 필요할 때 여는 사람이라면 트레이 시작이 더 깔끔할 수 있습니다.

중요한 것은 \'Slack 자동 실행\'과 \'Slack을 화면에 표시해서 시작\'이 같은 설정이 아니라는 점입니다. Slack이 분명 자동 실행되고 있는데 부팅할 때마다 창이 안 보여 이상했다면 Windows 시작 프로그램을 다시 등록하기 전에 Slack의 시작 시 표시 설정부터 확인해볼 만합니다.
