워드프레스 사이트를 여러 명이 함께 운영하면 가장 쉬운 방법은 모두에게 관리자 권한을 주는 것입니다.

하지만 글만 쓰는 사람에게 플러그인 삭제와 사용자 관리 권한까지 줄 필요는 없고, 계정 하나가 탈취됐을 때 피해 범위도 훨씬 커집니다.

워드프레스에는 관리자, 편집자, 글쓴이, 기여자, 구독자처럼 역할이 나뉘어 있죠. 필요한 작업만 할 수 있도록 권한을 나누는 것이 보안과 운영 모두에서 유리합니다.

## 1. 관리자는 사이트 전체를 바꿀 수 있다

관리자 권한은 플러그인과 테마 관리, 설정 변경, 다른 사용자 관리처럼 사이트 전체에 영향을 주는 기능을 사용할 수 있습니다.

단순히 글을 쓰고 사진을 올리는 업무에는 필요 이상의 권한입니다.

관리자 계정이 많아질수록 비밀번호 관리와 계정 보안도 어려워집니다. 운영 책임이 있는 최소 인원에게만 관리자 권한을 두는 편이 안전하죠.

## 2. 편집자는 콘텐츠 운영에 적합

편집자는 자신의 글뿐 아니라 다른 사용자의 글도 관리하고 발행할 수 있습니다.

여러 필자의 원고를 검토하고 수정하는 담당자라면 관리자보다 편집자 역할이 더 맞는 경우가 많습니다.

사이트 설정과 플러그인까지 건드릴 필요 없이 콘텐츠 흐름만 관리할 수 있어 실수 범위를 줄일 수 있습니다. 콘텐츠 책임자와 기술 관리자를 분리하기에도 좋죠.

## 3. 글쓴이와 기여자의 차이

글쓴이는 자신의 글을 작성하고 발행할 수 있으며 미디어 업로드도 가능한 역할입니다.

반면 기여자는 자신의 글을 작성할 수 있지만 직접 발행할 수 없어 편집자의 검토 과정을 거치게 만들 수 있습니다.

외부 필자나 처음 협업하는 사람에게는 기여자 역할이 더 안전할 수 있습니다. 원고 품질과 사이트 사용 방식이 확인된 뒤 필요한 경우 권한을 올리는 편이 낫습니다.

## 4. 구독자는 가장 제한적

구독자는 기본적으로 자신의 프로필을 관리하고 사이트에 로그인하는 정도의 제한된 권한을 가집니다.

회원 기능이 필요한 사이트에서 콘텐츠 편집 권한 없이 계정만 제공할 때 사용할 수 있죠.

단순 방문자에게 계정을 만들 필요가 없다면 회원 가입 기능 자체를 열어둘 이유도 적습니다. 사이트 목적과 맞지 않는 회원 기능은 불필요한 계정 관리 부담을 만들 수 있습니다.

## 5. 퇴사와 협업 종료 뒤 계정 정리

외주 작업이나 단기 협업이 끝났는데 계정을 그대로 두면 몇 달 뒤에도 로그인 가능한 상태가 남을 수 있습니다.

협업 종료 시 계정을 삭제하거나 권한을 낮추는 절차를 정해두는 편이 좋죠.

작성한 글이 있는 사용자를 삭제할 때는 콘텐츠를 다른 사용자에게 넘길지 확인하셔야 합니다. 계정 정리와 글 삭제가 같은 작업으로 처리되지 않도록 주의할 필요가 있습니다.

## 6. 새 사용자 기본 역할도 확인

회원 가입을 허용한 사이트라면 일반 설정의 새 사용자 기본 역할을 확인하시면 되죠.

실수로 높은 권한이 기본값으로 지정돼 있으면 가입한 사용자에게 예상보다 많은 기능이 열릴 수 있습니다.

공개 회원 가입이 필요하지 않은 사이트라면 가입 허용 자체를 꺼두는 것도 방법입니다. 필요한 사용자는 관리자가 직접 추가하는 편이 관리가 단순합니다.

## 7. 사용자 정의 권한은 신중하게

기본 역할로 부족한 경우 권한 편집 플러그인을 이용해 특정 기능만 추가하거나 제거할 수 있죠.

다만 권한 구조를 복잡하게 만들면 누가 무엇을 할 수 있는지 나중에 파악하기 어려워질 수 있습니다.

처음에는 기본 역할로 운영하고 정말 필요한 기능이 확인됐을 때만 세부 권한을 조정하는 편이 좋습니다. 권한은 많을수록 편한 것이 아니라 필요한 만큼만 주는 것이 관리하기 쉽죠.

## 8. 권한은 신뢰보다 사고 범위의 문제

저는 사용자 권한을 사람을 믿느냐의 문제로 보지 않습니다.

믿는 사람이라도 계정이 탈취되거나 실수로 설정을 바꿀 수 있기 때문에 필요한 작업 범위만 열어두는 것이 서로에게 안전합니다.

관리자, 편집자, 글쓴이, 기여자 역할을 업무에 맞춰 나누고 협업 종료 계정을 바로 정리하시면 됩니다. 모두에게 관리자 권한을 주는 편리함은 짧지만 문제가 생겼을 때 복구 범위는 훨씬 커집니다.

권한을 나눠두면 사고가 생겼을 때 확인 범위도 줄어듭니다. 글쓴이 계정에서 문제가 생겼다면 플러그인과 테마 설정까지 바뀌었을 가능성을 먼저 걱정하지 않아도 되죠.

운영 인원이 늘어날수록 최소 권한 원칙이 관리 시간을 줄이는 효과도 커집니다.
