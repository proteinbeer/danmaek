일곱 개의 대죄: 오리진은 넷마블에프앤씨가 만들고 넷마블이 서비스하는 오픈월드 액션 RPG입니다. 전 세계 누적 5,500만 부 판매를 기록한 일곱 개의 대죄 IP를 바탕으로 브리타니아 대륙을 탐험하며 영웅 교체와 무기 조합, 멀티 액션을 즐깁니다. 2026년 3월 모바일을 포함해 전 플랫폼으로 정식 출시됐습니다.

8월 27일 0.5주년 페스티벌 업데이트로 원작의 마지막 단원 '반'이 신규 영웅으로 추가되면서 대죄단 7인이 완성체를 갖췄고, 이를 기념하는 쿠폰이 9월 초 기준으로 여전히 입력되고 있습니다.

## 1. 9월 초 기준 사용 가능한 최신 쿠폰

9월 8일 기준으로 재확인된 일곱 개의 대죄: 오리진 사용 가능 코드는 다음과 같습니다. 0.5주년 기념 코드 3종이 가장 최신이며 사용 가능성이 높습니다.

| 쿠폰 코드 | 보상 |

| 7DSORIGIN05HALF | 0.5주년 기념 보상 패키지 |

## 2. 0.5주년 페스티벌 코드

0.5주년 페스티벌과 함께 공개된 아래 코드들은 공개된 지 얼마 안 돼 9월 초 입력이 가능합니다. 보상은 우편함으로 지급되며, 선착순 소진 시 조기 종료될 수 있습니다.

- 7DSORIGIN05HALF
- 7DS05ANNIV
- ORIGIN05TH

## 3. 코드 입력 방법

일곱 개의 대죄: 오리진은 게임 내 설정에서 쿠폰을 입력합니다. PS5·iOS 유저는 별도 웹 페이지에서 계정 정보(PID)와 함께 입력해야 합니다.

1. 게임 화면 우측 상단의 [메뉴(≡)]를 누릅니다.
2. 좌측 아이콘 중 [환경설정(⚙️)]을 선택합니다.
3. [계정] 탭에서 [쿠폰 입력]의 [사용] 버튼을 누릅니다.
4. 쿠폰 번호를 대소문자 구분해 입력하고 확인합니다.
5. 게임 재접속 후 우편함에서 보상을 수령합니다.

## 4. 계정당 1회 사용과 만료 코드 주의

쿠폰은 계정당 1회 사용할 수 있으며 서버별로 중복 입력이 불가능합니다. 출시 직후 공개된 ORIGINX, ORIGINDISCORD, ORIGINSTEAM 등은 안내된 기간이 지났기 때문에 계정에 따라 만료됐을 수 있습니다.

가장 확실한 건 0.5주년 코드 3종입니다. 우선 입력하고, 나머지는 오류가 나면 만료로 판단하시기 바랍니다.
