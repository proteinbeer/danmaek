DNS over HTTPS(DoH)는 DNS 질의를 HTTPS 안에 넣어 암호화하는 방식입니다. 웹사이트 주소를 IP 주소로 찾는 과정이 평문 DNS보다 네트워크 중간에서 쉽게 읽히거나 변조되는 것을 줄이는 것이 핵심입니다.

하지만 이름에 HTTPS가 들어간다고 해서 VPN처럼 인터넷 연결 전체를 암호화하거나 IP 주소를 숨겨주는 기능은 아닙니다. DoH를 켤지 결정하려면 먼저 보호 범위를 정확히 아는 것이 좋습니다.

## 일반 DNS와 무엇이 다른가

DNS는 danmaek.com 같은 도메인 이름을 서버의 IP 주소로 찾는 역할을 합니다.

전통적인 DNS 질의는 일반적으로 별도의 DNS 프로토콜로 전달됩니다. DoH는 이 질의와 응답을 HTTPS 연결 안에서 암호화합니다.

따라서 같은 네트워크에 있는 제3자가 DNS 질의 내용을 단순히 들여다보거나 중간에서 수정하기는 더 어려워집니다.

## DoH를 켜도 방문 사실이 완전히 숨겨지는 것은 아닙니다

DoH가 보호하는 것은 DNS 질의입니다. 사용자의 공인 IP를 바꾸지 않고 인터넷 트래픽 전체를 VPN 터널로 보내지도 않습니다.

웹사이트에 실제로 접속하려면 목적지 서버와 네트워크 연결이 이루어져야 하므로 DoH 하나만으로 ‘어떤 사이트를 이용했는지 아무도 알 수 없다’고 이해하면 과장입니다.

개인정보 보호 기능을 비교할 때는 DNS 암호화와 VPN을 같은 기능으로 취급하지 않는 것이 중요합니다.

## Windows와 브라우저 설정이 따로 있을 수 있습니다

Windows에서 암호화 DNS를 설정했더라도 브라우저가 자체 Secure DNS 설정을 사용할 수 있습니다. 반대로 운영체제는 일반 DNS를 사용하면서 브라우저만 DoH를 사용할 수도 있습니다.

그래서 DNS 동작을 확인할 때는 어느 계층에서 설정했는지 알아야 합니다.

특정 브라우저에서만 사이트 접속 문제가 발생한다면 브라우저의 보안 DNS 설정을 확인하고, PC 전체에서 같은 문제가 발생한다면 운영체제나 네트워크의 DNS 설정도 함께 확인할 수 있습니다.

## 회사와 학교에서는 함부로 바꾸지 않는 편이 낫습니다

기업이나 학교 네트워크는 내부 도메인, 보안 필터, 접근 정책을 위해 지정 DNS를 사용할 수 있습니다. 사용자가 브라우저에서 별도의 DoH 제공자를 강제로 선택하면 내부 주소가 해석되지 않거나 조직의 정책과 충돌할 수 있습니다.

관리되는 PC라면 개인용 PC와 같은 기준으로 설정을 바꾸기보다 조직의 네트워크 정책을 따르는 것이 우선입니다.

## DoH를 켜면 인터넷이 빨라질까

DoH는 속도 향상 기능이 아닙니다.

DNS 제공자를 바꾸면서 이름 조회 시간이 달라질 수는 있지만, 파일 다운로드 대역폭이나 게임 서버까지의 기본 회선 속도를 DoH 자체가 높여주지는 않습니다.

오히려 ‘DoH를 켰더니 다운로드가 몇 배 빨라진다’처럼 회선 속도 개선 기능으로 이해하면 문제 원인을 잘못 찾을 수 있습니다.

## 어떤 DNS 제공자를 선택해야 하나

Windows나 브라우저가 지원하는 신뢰할 수 있는 DNS 제공자를 선택하고, 해당 서비스의 개인정보 처리 방식도 함께 확인하는 것이 좋습니다.

암호화되지 않은 DNS에서는 로컬 네트워크나 ISP가 DNS 질의를 처리할 수 있고, 외부 DoH 제공자를 사용하면 DNS 질의의 처리 주체가 그 제공자로 바뀔 수 있습니다. 암호화 여부뿐 아니라 누구에게 DNS를 맡기는지도 선택의 일부입니다.

DoH는 켜야만 안전하고 끄면 위험한 식의 단순한 옵션은 아닙니다. 개인용 네트워크에서 DNS 질의의 기밀성과 무결성을 높이는 데 유용하지만, 회사 내부 DNS처럼 기존 네트워크 정책이 중요한 환경에서는 별도의 고려가 필요합니다.

핵심은 기능의 범위를 정확히 아는 것입니다. DoH는 DNS 질의를 암호화합니다. 공인 IP를 숨기거나 모든 트래픽을 익명화하는 기능은 아닙니다.
