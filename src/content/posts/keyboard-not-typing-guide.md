키보드가 안 쳐질 때 가장 당황스러운 이유는 **원인이 하나가 아니라 여러 곳에 흩어져 있기 때문**입니다. 무선이면 연결이, 노트북이면 윈도우 설정이, 오래된 키보드면 접점 문제가 각각 원인이 될 수 있죠.

이 글에서는 고장인지 설정인지 판단하기 좋은 순서대로 정리했습니다. 대부분의 입력 문제는 다음 4단계 안에서 해결됩니다.

## 1. 무선 키보드의 연결부터 확인

무선 키보드가 갑자기 먹통이 되면 먼저 **전원과 연결**을 의심합니다.

- 키보드에 배터리 표시가 있으면 전원 상태를 확인합니다. 약하면 즉시 교체하거나 충전합니다.
- 수신기를 뽑았다 다시 꽂고, 다른 USB 포트(가능하면 USB 2.0)로 바꿔봅니다.
- 블루투스 키보드는 페어링 정보를 삭제하고 다시 연결합니다.
- 노트북의 블루투스 토긘이 꺼져 있진 않은지, 절전 모드에서 연결이 끊겼다가 복구되지 않은 것은 아닌지 확인합니다.

연결 문제는 거의 대부분 위 확인으로 해결됩니다. 유선 키보드라면 USB 단자 접촉을 점검하고 다른 포트도 시도해보세요.

## 2. 필터 키와 윈도우 설정 확인

특정 키만 안 되거나, 키를 눌러도 긴 입력으로 인식되는 것은 윈도우의 **접근성 기능**이 원인인 경우가 많습니다.

- 시작 메뉴 검색에서 "접근성 키보드 설정"을 연 뒤 **필터 키**가 켜져 있으면 끕니다. 필터 키는 잠깐 누른 입력을 무시하는 기능입니다.
- 고정 키/전환 키가 켜져 있으면 shift 같은 키가 계속 눌린 상태로 남아 입력이 이상해집니다. 이것도 꺼주세요.
- "게임 모드"나 키보드 제조사 소프트웨어의 매크로 설정이 특정 키를 잡아두고 있는지도 확인합니다.
- 키보드 레이아웃이 한국어(103/106키)로 되어 있는지도 확인합니다. 레이아웃이 어긋나면 숫자·특수키가 엉뚱하게 출력됩니다.

설정 창이 어디 있는지 모르겠다면 시작 메뉴 통합 검색에서 "키보드"라고만 쳐도 관련 설정이 바로 나옵니다.

## 3. 드라이버와 입력 장치 상태 확인

한 번도 한 번에 몇 개의 키가 동시에 눌렸다 뗐다 되는 것처럼 보이는데, 실제로는 **드라이버 오류**로 입력이 지연되는 경우가 있습니다.

- 장치 관리자 → 키보드에 느낌표가 있는지 확인합니다.
- 느낌표가 있으면 우클릭 → 드라이버 업데이트를 실행합니다.
- 그래도 해결되지 않으면 장치를 우클릭 → **장치 제거** 후 재부팅합니다. 윈도우가 재부팅하면서 드라이버를 다시 설치합니다.
- USB 허브(분배기)를 거치고 있다면 본체 뒷면 포트에 직접 꽂아 테스트합니다. 허브 전원이 약하면 키 입력이 끊깁니다.

드라이버 문제는 소리가 아니라 입력만 멈추는 경우가 많아 발견이 어렵습니다. 장치 제거 → 재부팅은 생각보다 많은 입력 문제를 해결합니다.

## 4. 일반 키는 되는데 일부만 안 될 때

"일반 타이핑은 되는데 특정 키만" 안 된다면 원인이 좁혀집니다. 대부분 먼지나 물리적 접점 문제입니다.

- 키캡을 떼어내고 그 아래 접점을 **에어 스프레이로 불어내면** 접촉 불량이 풀리는 경우가 많습니다.
- 노트북이라면 디스플레이 사이즈에 겹친 이물질이 눌려 있는지, 키캡이 비스듬하게 눌러져 있지 않은지 봅니다.
- Windows 키나 Fn 키만 안 되면 그 키에 연결된 **기능 잠금(F-Lock)** 설정을 확인합니다.
- 키보드 전체가 아닌 특정 줄만 안 되면 스위치나 케이블 단선일 가능성이 있어야, 이 경우는 교체가 현실적입니다.

이물질이 원인이라면 청소만으로 해결됩니다. 청소 후에도 동일하다면 해당 스위치의 수명이 다했다고 보시면 됩니다.

## 5. 아무것도 안 눌리는 그 순간, 긴급 확인

입력이 완전히 멈추었을 때는 "키보드가 잠겼는지"부터 확인해야 합니다.

- Windows 키 + L 로 화면 잠금이 걸린 것은 아닌지, Ctrl + Alt + Delete 화면에서 키보드가 살아있는지 확인합니다.
- 노트북은 외장 키보드를 꽂았을 때 **내장 키보드가 자동으로 잠기는 경우**가 있습니다. BIOS나 설정에서 이를 다시 켜야 할 수 있습니다.
- 급할 때는 화상 키보드(시작 메뉴 → "화상 키보드")를 띄워 마우스로 입력하며 버퍼링 합니다.
- 재부팅 후에도 안 된다면 다른 컴퓨터에 연결해 하드웨어 이상 여부를 판단합니다.

키보드는 대부분 재부팅으로 복구되는 일시적 오류가 많습니다. 그래도 같은 문제가 반복된다면 장치 제거 → 재부팅까지 해보시기 바랍니다.
