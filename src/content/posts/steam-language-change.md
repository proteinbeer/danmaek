상점 페이지에는 한국어 지원이라고 적혀 있는데 게임을 실행하면 영어로 나오는 경우가 있습니다.

이때 게임을 다시 설치하기보다 스팀 클라이언트 언어, 게임별 언어, 게임 안의 설정을 나눠서 확인하는 편이 빠릅니다.

스팀의 표시 언어와 게임 언어는 항상 같은 설정이 아닙니다.

게임별 속성에서 별도 언어를 선택할 수 있고 일부 게임은 실행 뒤 내부 옵션에서 다시 언어를 정해야 하죠.

## 1. 상점 페이지의 지원 범위 확인

한국어 지원이라는 표시도 인터페이스, 음성, 자막이 각각 다를 수 있습니다.

한국어가 체크되어 있어도 음성은 영어만 제공되고 메뉴와 자막만 한국어인 게임이 흔합니다.

먼저 자신이 원하는 부분이 실제로 지원되는지 확인하시는 것이 좋습니다.

음성까지 한국어라고 생각하고 설정을 찾다가 실제 지원 범위가 자막뿐인 경우도 있기 때문입니다.

## 2. 게임별 언어 먼저 변경

스팀 라이브러리에서 게임 속성을 열면 언어 항목을 제공하는 게임이 있습니다.

원하는 언어를 선택하면 필요한 언어 파일이 추가로 다운로드될 수 있습니다.

선택 뒤 바로 게임을 켜기보다 다운로드가 끝났는지 확인합니다.

언어 팩 용량이 큰 게임은 음성 파일 때문에 생각보다 많은 데이터를 받을 수 있습니다.

## 3. 스팀 클라이언트 언어 영향

일부 게임은 처음 실행할 때 스팀 클라이언트의 언어를 기준으로 기본값을 고릅니다.

스팀 자체가 영어로 설정되어 있다면 게임도 영어를 기본으로 선택하는 경우가 있습니다.

스팀 설정의 인터페이스에서 클라이언트 언어를 바꾸면 스팀을 다시 시작해야 할 수 있습니다.

모든 게임을 한국어로 쓰고 싶다면 클라이언트 언어도 한국어로 맞춰두는 편이 편합니다.

## 4. 게임 내부 설정이 따로 있는 경우

스팀 속성에서 한국어를 선택했는데도 영어가 나온다면 게임 내부의 언어 메뉴를 확인합니다.

일부 게임은 스팀 설정을 참고하지 않고 자체 설정 파일에 마지막 언어를 저장합니다.

외부 런처를 한 번 더 거치는 게임도 마찬가지입니다.

스팀은 한국어인데 외부 런처가 영어라면 그 런처의 설정에서 언어를 다시 지정해야 할 수 있습니다.

## 5. 언어 파일이 꼬였을 때

언어 변경 도중 다운로드가 중단됐거나 파일이 손상되면 자막이 비거나 글자가 이상하게 나올 수 있습니다.

이럴 때는 게임 파일 무결성 검사를 진행해 빠진 언어 파일을 다시 받는 방법이 있습니다.

모드를 사용 중이라면 번역 모드가 공식 언어 파일보다 우선해서 로딩되는지도 확인하셔야 합니다.

예전에 설치한 한글 패치가 정식 한국어 지원 뒤 오히려 충돌을 만드는 경우도 있습니다.

## 6. 한국어 지원 표시는 업데이트될 수 있다

게임 출시 당시 한국어가 없었어도 이후 패치로 추가되는 경우가 있고 반대로 특정 플랫폼만 지원 범위가 다른 사례도 있습니다.

오래된 블로그 글보다 현재 스팀 상점 페이지와 게임 설정을 기준으로 보는 편이 정확합니다.

저는 언어 문제에서 재설치를 가장 마지막에 두는 것이 좋다고 봅니다.

지원 범위, 게임별 언어, 클라이언트 언어, 내부 설정 순서로 보면 대부분은 파일을 전부 다시 받지 않고 해결할 수 있습니다.

## 7. 언어 변경 뒤 세이브와 모드도 확인

대부분의 게임은 언어를 바꿔도 세이브 진행이 그대로 유지됩니다. 하지만 번역 모드나 글꼴 모드를 함께 쓰는 경우에는 공식 언어 파일과 충돌해 메뉴가 깨지거나 일부 문장이 섞여 나올 수 있습니다.

정식 한국어가 새로 추가된 게임이라면 예전에 설치한 비공식 한글 패치를 먼저 제거하는 편이 좋습니다. 패치가 원본 파일을 덮어쓴 방식이라면 제거 뒤 무결성 검사를 진행해 공식 파일을 다시 받는 것이 깔끔합니다.

언어를 바꿨는데 용량이 크게 늘어도 이상한 현상은 아닙니다. 음성 언어까지 바뀌는 게임은 고음질 음성 파일을 따로 내려받아 수 기가바이트 이상 추가될 수 있습니다.

저는 언어 설정을 단순 메뉴 번역 옵션으로만 보지 않는 편이 좋다고 생각합니다. 게임마다 자막, 음성, 인터페이스가 따로 움직일 수 있으므로 원하는 결과가 무엇인지 정하고 각 항목을 확인하면 훨씬 빠르게 맞출 수 있습니다.

게임마다 언어 설정 구조가 다르다는 점도 기억할 필요가 있습니다. 어떤 게임은 스팀 속성만 바꾸면 끝나지만, 다른 게임은 첫 실행 런처와 게임 내부 메뉴까지 각각 확인해야 합니다.

특히 여러 언어를 번갈아 쓰는 분이라면 공식 음성과 자막 조합을 먼저 확인하고 변경하시는 것이 편합니다. 언어 파일을 계속 다시 받는 일을 줄일 수 있고, 모드와 공식 번역이 충돌하는 상황도 미리 피할 수 있습니다.
