와이파이는 연결됐다고 나오는데 인터넷만 안 되는 경우가 있습니다. 이럴 때 공유기부터 건드리기 전에 컴퓨터와 공유기 중 어디가 문제인지 먼저 구분하는 것이 중요하죠.

와이파이에 연결되면 대부분 인터넷도 함께 되지만, 가끔 와이파이 연결은 되어 있는데 인터넷(인터넷 없음, 연결 안 됨)만 되지 않는 경우가 있습니다. 이때 공유기부터 재부팅하기 전에, 문제가 컴퓨터 쪽인지 공유기나 인터넷 회선 쪽인지 먼저 구분하는 것이 빠른 해결의 핵심입니다. 구분하는 방법부터 차근차근 확인해보시기 바랍니다.

## 1. 다른 기기에서 확인

휴대폰도 같은 와이파이에 연결해서 인터넷이 되지 않는다면 컴퓨터 문제보다 공유기나 회선 문제일 가능성이 높습니다.

와이파이 연결은 되는데 인터넷이 안 되는 상황에서 가장 먼저 해볼 일은 **다른 기기로 같은 와이파이를 테스트**하는 것입니다. 휴대폰이나 다른 노트북을 같은 와이파이에 연결해서 인터넷이 되는지 확인해보시면 됩니다.

- 다른 기기에서도 인터넷이 안 된다면 → 공유기나 인터넷 회선 문제
- 다른 기기에서는 인터넷이 잘 된다면 → 해당 컴퓨터(노트북) 쪽 문제

이렇게 원인 범위를 좁히면 불필요한 시도를 줄일 수 있습니다. 휴대폰에서도 안 된다면 아래의 공유기 재부팅 단계로 넘어가시면 됩니다.

## 2. 와이파이 다시 연결

컴퓨터에서 해당 와이파이를 연결 해제한 뒤 다시 연결해보시면 됩니다. 그래도 안 된다면 네트워크를 삭제하고 비밀번호를 다시 입력해 연결하는 방법도 있죠.

컴퓨터 쪽이 문제라면 와이파이를 **연결 해제 후 다시 연결**해보시면 됩니다. 작업 표시줄 오른쪽의 와이파이 아이콘에서 연결된 네트워크를 선택해 끊고, 다시 연결하면 임시 오류가 해결되는 경우가 많습니다.

그래도 안 된다면 해당 네트워크를 **완전히 삭제(잊기)**한 뒤 와이파이 비밀번호를 다시 입력해 연결해보시면 됩니다. 저장된 네트워크 정보가 잘못되었을 때 이 방법이 도움이 됩니다. 연결 후에도 인터넷이 안 된다면 네트워크 어댑터 상태를 확인해보아야 합니다.

## 3. 공유기 재부팅

여러 기기에서 모두 인터넷이 안 될 때는 공유기의 전원을 끄고 잠시 기다린 뒤 다시 켜보시면 됩니다.

여러 기기에서 모두 인터넷이 안 된다면 공유기나 인터넷 회선 문제일 가능성이 높습니다. 이때는 공유기의 전원을 완전히 껐다가 **30초 정도 기다린 뒤** 다시 켜보시면 됩니다. 공유기는 오래 켜두면 캐시와 연결 상태가 쌓여 일시적으로 문제를 일으키는 경우가 있기 때문입니다.

공유기 재부팅 후에도 안 된다면, 공유기와 인터넷 모뎀(광케이블·케이블 모뎀)을 같이 재부팅해보시면 됩니다. 인터넷 회선 문제는 통신사 측에서 발생한 것일 수도 있는데, 이 경우 공유기와 모뎀 재부팅으로도 해결되지 않으면 통신사 고객센터에 문의하는 것이 좋습니다.

## 4. 한 기기만 문제라면

컴퓨터 한 대에서만 문제가 생긴다면 윈도우 네트워크 문제 해결과 네트워크 어댑터 드라이버를 확인해보시는 편이 좋습니다.

다른 기기에서는 인터넷이 정상인데 이 컴퓨터에서만 안 된다면, 컴퓨터의 네트워크 어댑터나 설정 문제입니다. 윈도우의 **네트워크 문제 해결사**(설정 → 시스템 → 문제 해결 또는 제어판의 네트워크 문제 해결)를 실행해보시면 됩니다. 윈도우가 네트워크 문제를 자동으로 진단하고 수정을 시도합니다.

또한 **장치 관리자 → 네트워크 어댑터**에서 와이파이 어댑터에 오류 표시가 없는지 확인하고, 드라이버를 최신 버전으로 업데이트해보시면 됩니다. 네트워크 어댑터를 한 번 껐다 켜는 방법, 또는 윈도우의 네트워크 초기화 명령을 사용해 어댑터 설정을 초기화하는 방법도 있습니다.

## 5. 간단한 원인 확인

위에서 해결되지 않는다면 몇 가지 환경적인 원인도 확인해보시면 됩니다. 노트북의 비행기 모드가 켜져 있지는 않은지, 공유기에서 특정 기기의 인터넷 접근이 차단되고 있지는 않은지 확인해보시면 됩니다. 자녀 보호나 MAC 주소 필터링 같은 공유기 설정이 적용되어 있다면 해당 컴퓨터만 인터넷이 막힐 수 있습니다.
