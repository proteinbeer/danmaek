휴대폰이나 PC에 와이파이 연결 표시는 뜨는데 인터넷 없음이라고 나오는 경우가 있습니다. 이 문구는 무선 연결 자체와 인터넷 연결이 서로 다른 단계라는 점을 보여줍니다.

기기는 공유기와 정상적으로 연결돼 있어도 공유기가 통신사 회선과 연결되지 않았거나 IP와 DNS 문제가 생기면 인터넷은 사용할 수 없습니다. 공유기 재부팅부터 하기보다 어디까지 통신되는지 나누는 편이 좋습니다.

1. 다른 기기 비교

같은 와이파이에 연결된 다른 휴대폰이나 PC가 인터넷을 사용할 수 있는지 확인합니다. 한 기기만 문제라면 공유기 전체보다 해당 기기의 IP와 DNS, 네트워크 설정을 먼저 볼 수 있습니다.

모든 기기가 동시에 인터넷이 안 된다면 공유기 WAN과 모뎀 상태를 확인해야 합니다. 이 비교가 가장 빠르게 문제 범위를 나눠줍니다.

2. 공유기 주소 접속

인터넷이 안 돼도 공유기 관리 주소에는 접속되는지 확인할 수 있습니다. 공유기 화면이 열린다면 기기와 공유기 사이 무선 연결은 살아 있다는 뜻입니다.

공유기조차 열리지 않는다면 와이파이 연결 상태나 IP 주소부터 다시 확인합니다. 인터넷과 로컬 연결을 분리하면 불필요한 DNS 변경을 줄일 수 있습니다.

3. IP와 게이트웨이

PC의 IPv4 주소와 기본 게이트웨이를 확인합니다. 169.254 주소가 잡혀 있거나 게이트웨이가 비어 있으면 공유기에서 정상 주소를 받지 못한 상태일 수 있습니다.

이 경우 네트워크를 잊고 다시 연결하거나 DHCP 상태를 확인합니다. 정상 주소를 받은 뒤에도 인터넷이 안 될 때 다음 단계로 넘어갑니다.

4. DNS만 문제인지 확인

공유기와 외부 IP에는 통신되는데 사이트 이름만 열리지 않는다면 DNS 문제일 수 있습니다. DNS를 바꾸기 전에 다른 사이트와 앱에서도 같은지 확인합니다.

브라우저 하나만 문제라면 보안 DNS나 캐시 설정도 볼 수 있습니다. 인터넷 없음 문구 하나만 보고 DNS를 무조건 변경하는 것은 좋은 첫 단계가 아닙니다.

5. 공유기 바깥 회선

모든 기기가 공유기에는 연결되지만 인터넷만 안 된다면 공유기의 WAN 상태와 모뎀 또는 광단말기 표시등을 확인합니다. 통신사 장애가 있는지 공식 안내도 함께 볼 수 있습니다.

공유기를 재부팅할 때는 모뎀과 전원 순서를 제품 안내에 맞춰 진행합니다. 회선 신호 자체가 사라진 상황이라면 PC 설정을 바꿔도 해결되지 않습니다.

와이파이 연결이라는 표시는 공유기까지 무선으로 닿았다는 뜻이지 인터넷까지 정상이라는 보장은 아닙니다. 이 차이를 알면 연결됨과 인터넷 없음이 동시에 보이는 상황도 이상하지 않습니다.

다른 기기, 공유기 주소, 외부 인터넷 순서로 한 단계씩 확인하시면 됩니다. 어느 지점까지 정상인지 찾으면 문제를 고칠 위치도 자연스럽게 정해집니다.

공용 와이파이에서는 로그인 화면을 한 번 거쳐야 인터넷이 열리는 경우도 있습니다. 호텔과 카페에서만 이런 증상이 생긴다면 브라우저를 열어 인증 페이지가 나타나는지 확인해보는 것도 좋습니다.

6. 연결됨과 인터넷됨을 분리해서 보기

한 번 해결됐다고 끝내기보다 다른 기기가 같은 와이파이에서 인터넷 되는지을 기준값으로 남겨두시는 편이 좋습니다. 다음에 문제가 생기면 문제 기기의 IP와 기본 게이트웨이 확인하면서 바로 비교할 수 있기 때문입니다. 와이파이 연결 표시는 공유기까지 붙었다는 뜻이지 외부 인터넷까지 보장하지 않음이라는 특성 때문에 같은 오류 문구라도 실제 원인은 달라질 수 있습니다.

그래서 공용 DNS부터 바꾸는 것은 마지막 쪽으로 미루는 게 좋습니다. 한 기기만 안 되면 주소 할당과 접근 제어 확인한 뒤에도 변화가 없을 때만 더 큰 설정을 건드리십시오. 필요하면 모든 기기가 안 되면 WAN과 통신사 구간으로 넘어가기하면서 장치 하나의 문제인지 네트워크 전체 문제인지 확인하시면 됩니다.

이 글의 증상에서는 다른 기기가 같은 와이파이에서 인터넷 되는지이 가장 재현성이 높은 확인값입니다. 한 번에 여러 설정을 바꾸지 마시고 한 기기만 안 되면 주소 할당과 접근 제어 확인한 결과부터 비교하시면 같은 문제가 생겨도 다시 처음부터 점검할 필요가 없습니다.

공유기에서 기기별 접근 제어나 사용 시간 제한을 쓰고 있다면 특정 장치만 인터넷이 막힐 수도 있습니다. IP 주소와 게이트웨이는 정상인데 한 기기만 외부 접속이 안 된다면 차단 목록과 자녀 보호 규칙도 확인해 보시는 게 좋습니다.
