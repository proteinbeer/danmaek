모탈 셸 2의 무기는 근접 주무기 8개와 보조 무기 8개로 나뉩니다. 주무기는 아이코노클라스트, 도끼와 단검, 베테랑의 전투 도끼, 대순교자의 검, 흑요석 망치, 검은 바늘, 액사타나, 시계태엽 낫이고 보조 무기는 나일샷, 잊힌 석궁, 회수한 트레뷰셰트 도끼, 음유시인의 류트, 트라이악 리피터, 발리스타주카, 저주받은 아이, 우리에 갇힌 하이스트릭스로 구성됩니다. 무기는 특정 셸에 묶이지 않아 익숙한 무기를 그대로 두고 셸만 바꿔 쓸 수 있죠.

이 글에서는 주무기와 보조 무기 16종의 획득 경로를 지역별로 묶고, 전투 성격에 맞는 선택 기준과 강화 재료를 아끼는 사용 순서를 정리했습니다. 모든 무기를 모으면 관련 업적도 함께 진행되므로 수집 목표로 잡기에도 좋습니다.

## 1. 주무기 8종과 획득 경로

| 주무기 | 획득 경로 |
|---|---|
| 아이코노클라스트 | 프롤로그에서 자동 획득 |
| 도끼와 단검 | 머시룸 빌리지 예배당 열쇠 → 슈라인 오브 트라이얼 던전 |
| 베테랑의 전투 도끼 | 셰터드 비컨 북서쪽 킹스 크립트 |
| 대순교자의 검 | 글룸셰이드 그로브 북서쪽 마터스 프리즌 던전 |
| 흑요석 망치 | 아웃스커츠 오브 마몬 남서쪽 옵시디아나이트 마인 |
| 검은 바늘 | 세스터스 게이트 쌍둥이 세스터 전투 보상 |
| 액사타나 | 더 사일런트 스텝 북동쪽 탑의 문 개방 |
| 시계태엽 낫 | 체임버 오브 비커밍 사리엘 최종 전투 |

근접 무기는 던전 끝 보상이거나 필드·보스 보상이라 본문처럼 지역별로 묶어 챙기면 빠짐 없이 정리됩니다. 첫 무기인 아이코노클라스트는 프롤로그에서 자동으로 얻으므로 이후 탐험 순서만 정하면 되죠.

## 2. 초반에 손에 넣는 주무기

아이코노클라스트는 다른 무기를 얻기 전까지 패링·경화·강공격 타이밍을 익히는 기준이 됩니다. 베테랑의 전투 도끼는 킹스 크립트의 몸에서 찾으며, 달리기 뒤 강공격이 두 번 회전해 보스전 리졸브 회복에 유용하죠. 도끼와 단검은 머시룸 빌리지에서 예배당 열쇠를 얻어 슈라인 오브 트라이얼을 끝까지 밀어야 합니다. 벽과 바닥 장치가 있어 전투만 하는 던전이 아니라 탐색도 필요합니다.

## 3. 중반과 후반 주무기

대순교자의 검은 마터스 프리즌에서 특정 방의 적을 모두 처리해야 무기 방이 열립니다. 흑요석 망치는 옵시디아나이트 마인의 예언자 미니보스를 잡으면 자동으로 획득하며, 피해량이 높은 만큼 공격 뒤 후딜을 먼저 확인하시는 편이 좋죠. 검은 바늘은 세스터스 게이트의 쌍둥이 세스터 전투 보상이고 액사타나는 더 사일런트 스텝 북동쪽 탑의 문을 연 뒤 안쪽에서 얻습니다. 시계태엽 낫은 사리엘 셸과 같은 흐름에서 부활용 무덤 네 개를 파괴하면 자동으로 들어오므로 셸과 무기, 보조 무기를 한 번에 정리하기 좋습니다.

## 4. 보조 무기 8종과 획득 경로

| 보조 무기 | 획득 경로 |
|---|---|
| 나일샷 | 프롤로그 시작 구간 |
| 잊힌 석궁 | 블랙리지 패스 북서쪽 플러디드 빌리지, 젖은 열쇠 |
| 회수한 트레뷰셰트 도끼 | 글룸셰이드 그로브 남쪽 레비지드 하이드아웃 마지막 방 |
| 음유시인의 류트 | 원 레그드 울프 선술집 무대 왼쪽 |
| 트라이악 리피터 | 캐스티게이터스 킵 아래 블랙웰 캐번 |
| 발리스타주카 | 게이트 오브 마몬 부근 센트리스 그레이브 미니보스 |
| 저주받은 아이 | 레버드 비컨 던전 중앙 기둥 파괴 |
| 우리에 갇힌 하이스트릭스 | 체임버 오브 비커밍 출구 근처 |

보조 무기의 획득 조건은 열쇠, 미니보스, 기믹 등이 서로 달라 목록을 놓고 확인하기 쉽습니다. 나일샷은 프롤로그에서 기본으로 받아 초반에 안전한 거리에서 적을 정리하는 습관을 들이는 데 그대로 쓰면 되죠.

## 5. 보조 무기 선택과 강화 순서

잊힌 석궁은 플러디드 빌리지에서 젖은 열쇠를 먼저 챙겨야 중앙 건물이 열립니다. 음유시인의 류트는 선술집 무대 왼쪽에 있어 그라구 퀘스트와 한 동선에서 챙기기 좋죠. 트라이악 리피터는 강화해 두면 정면 근접이 위험한 헥사포드 같은 보스에 원거리 공격을 넣기 좋고, 발리스타주카는 센트리스 그레이브 미니보스 보상이며 저주받은 아이는 추적 광선을 피해 중심 기둥을 부숴 얻습니다. 우리에 갇힌 하이스트릭스는 체임버 출구 근처에 있으니 시계태엽 낫과 함께 정리하시면 됩니다.

초반에는 강화 재료를 주무기 하나와 자주 쓰는 보조 무기 하나에 몰아주는 편이 효율적입니다. 표기 공격력만 보고 판단하기보다 공격 후 빠지는 속도, 사거리, 리졸브 회복을 함께 보며 투자 여부를 정하면 후반 빌드 실험이 쉬워지죠.
