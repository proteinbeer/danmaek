## 1. 지금 사용 가능한 최신 쿠폰

쿠키런: 킹덤 쿠폰은 공식 커뮤니티와 방송, 이벤트 때마다 배포됩니다. 코드는 데브플레이 계정당 1회만 사용할 수 있습니다.

## 2. 쿠폰 입력 방법 (데브플레이)

쿠키런: 킹덤 쿠폰은 게임 안이 아니라 **데브플레이 쿠폰 페이지**에서 입력합니다. 주소는 coupon.devplay.com/coupon/ck/ko입니다.

먼저 데브플레이 계정 정보를 확인해야 합니다. 게임 실행 후 상단 메뉴 버튼을 누르고 **환경설정 > 정보** 탭에서 데브플레이 계정을 확인할 수 있습니다.

쿠폰 페이지에 접속해 데브플레이 계정과 쿠폰 코드 16자리를 입력하고 상품 받기를 누르면 됩니다. 등록 후에는 게임을 완전히 종료했다가 다시 실행해야 보상이 들어옵니다.

보상은 게임 내 **우편함**에서 수령할 수 있습니다. 계정당 1회 등록이 원칙이니 코드 입력 전에 정확히 확인하는 것이 좋아요.

## 3. 쿠폰 자동 등록 사이트 사용법

쿠폰이 여러 개 쌓일 때는 하나씩 입력하기 번거로울 수 있습니다. 설탕노움의 비밀창고 같은 자동 등록 사이트를 이용하면 데브플레이 계정 하나로 여러 쿠폰을 한 번에 등록할 수 있죠.

물론 자동 등록 사이트는 계정 정보를 입력해야 하므로 신뢰할 수 있는 곳인지 확인 후 이용하는 편이 안전합니다. 공식 쿠폰 페이지에서 하나씩 입력해도 과정은 간단합니다.

## 4. 유효 기간은 짧은 편

쿠키런: 킹덤 쿠폰은 대부분 발표 직후 짧은 기간 동안만 사용할 수 있습니다. 9월에 확인된 코드들도 각각 9월 중순까지가 기한입니다.

쿠폰 등록 후 보상이 바로 보이지 않으면 게임을 재실행해 보세요. 우편함에 보상이 쌓여 있을 때가 많습니다. 우편함 보존 기간이 있으니 받을 기회가 있을 때 수령하는 것이 좋아요.

새 코드는 데브시스터즈 공식 커뮤니티와 방송에서 가장 먼저 공개됩니다. 주기적으로 확인하면 기한이 짧은 코드도 놓치지 않습니다.
