NAS, 프린터, 홈서버처럼 주소가 바뀌면 불편한 장비에는 같은 내부 IP를 계속 사용하게 만들고 싶을 때가 있습니다. 방법은 크게 두 가지입니다. 장비에서 직접 IP를 입력하거나, 공유기의 DHCP 예약 기능으로 특정 장비에 같은 주소를 배정하는 방식입니다.

가정에서는 DHCP 예약이 관리하기 편한 경우가 많습니다.

## DHCP 예약은 어떻게 동작하나

일반적인 가정용 공유기는 DHCP를 이용해 휴대폰과 PC에 내부 IP를 자동으로 나눠줍니다.

DHCP 예약을 설정하면 공유기는 특정 장비를 식별해 연결될 때마다 지정한 IP를 배정합니다. 장비 쪽 네트워크 설정은 여전히 ‘자동으로 IP 받기’ 상태로 둘 수 있습니다.

예를 들어 NAS에 192.168.0.50을 예약하면 재부팅하거나 다시 연결해도 공유기가 같은 주소를 주도록 관리할 수 있습니다.

## 장비에서 직접 고정 IP를 넣는 것과 무엇이 다른가

수동 고정 IP는 PC나 NAS 자체에 IP 주소, 서브넷, 게이트웨이, DNS 등을 직접 입력합니다.

DHCP 예약은 이 정보를 공유기가 관리합니다. 공유기를 교체하거나 내부 주소 대역을 바꿀 때도 한곳에서 예약 목록을 확인할 수 있다는 장점이 있습니다.

여러 장비에 각각 수동 값을 넣어두면 나중에 어떤 주소를 어디에 사용했는지 놓치기 쉽습니다. 잘못 관리하면 DHCP가 다른 기기에 같은 주소를 배정해 IP 충돌이 생길 수도 있습니다.

## 어떤 장비를 예약하면 유용할까

주소를 기억해서 접속하는 NAS나 홈서버, 네트워크 프린터가 대표적입니다.

포트포워딩의 대상이 되는 PC도 주소가 바뀌면 규칙이 엉뚱한 기기를 가리킬 수 있으므로 DHCP 예약과 잘 맞습니다.

반대로 일반 휴대폰이나 노트북처럼 내부 IP가 바뀌어도 상관없는 기기까지 전부 예약할 필요는 없습니다.

## 설정할 때 확인할 값

공유기 관리자 페이지에서 DHCP, LAN, Address Reservation, Static Lease처럼 표시된 메뉴를 찾습니다. 제조사마다 이름은 다릅니다.

예약하려는 장비의 MAC 주소와 원하는 내부 IP를 지정합니다. 이미 연결된 기기 목록에서 선택할 수 있는 공유기라면 직접 MAC 주소를 입력하지 않아도 되는 경우가 있습니다.

예약 후에는 장비의 네트워크 연결을 다시 시작하거나 DHCP 임대를 갱신한 뒤 실제로 지정한 주소를 받았는지 확인합니다.

## MAC 주소가 바뀌면 예약도 다른 장비로 인식될 수 있습니다

최근 휴대폰과 노트북은 개인정보 보호를 위해 와이파이 네트워크마다 임의 MAC 주소를 사용할 수 있습니다.

해당 네트워크에서 MAC 주소가 변경되면 공유기는 이전에 예약한 장비와 다른 장비로 인식할 수 있습니다. 반드시 주소를 고정해야 하는 기기라면 그 네트워크에서 사용하는 MAC 주소가 어떻게 설정되어 있는지 확인합니다.

## DHCP 예약이 항상 정답은 아닙니다

서버가 공유기와 무관하게 자체 네트워크 설정을 유지해야 하는 환경이나 DHCP 서버가 없는 네트워크에서는 수동 IP가 필요할 수 있습니다.

하지만 일반적인 집 네트워크에서 NAS, 프린터, 포트포워딩 대상 PC의 주소를 안정적으로 유지하는 목적이라면 DHCP 예약은 실수할 항목을 줄여줍니다.

핵심 차이는 ‘고정된 주소를 어디에서 관리하느냐’입니다. 장비에서 직접 관리하면 수동 고정 IP, 공유기가 같은 주소를 계속 배정하게 하면 DHCP 예약입니다. 집 안의 여러 기기를 관리한다면 한곳에서 목록을 볼 수 있는 DHCP 예약이 편한 경우가 많습니다.
