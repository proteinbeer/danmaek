유튜브에 자막 파일을 올린 뒤 자막 언어를 확인하려고 했는데 생각보다 메뉴가 바로 보이지 않았습니다.

자막을 넣었으니 같은 화면 어딘가에 동영상 언어 설정도 있을 것이라고 생각했는데 실제 유튜브 스튜디오에서는 자막을 추가하는 메뉴와 원본 동영상 언어를 정하는 메뉴가 나뉘어 있습니다.

저처럼 자막 파일까지 넣고 나서 언어 설정을 찾기 시작하면 같은 메뉴를 계속 들락거리기 쉽습니다. 자막 언어를 추가하려는 것인지, 동영상 자체의 원본 언어를 바꾸려는 것인지부터 구분하면 훨씬 빨리 찾을 수 있습니다.

## 1. 자막 언어 추가 위치

새로운 언어의 자막을 넣고 싶다면 유튜브 스튜디오의 자막 메뉴로 들어가면 됩니다.

왼쪽 메뉴에서 자막을 선택하고 영상을 고른 다음 언어 추가를 누릅니다. 원하는 언어를 선택한 뒤 자막 항목의 추가를 누르면 파일 업로드, 직접 입력 같은 방법을 선택할 수 있습니다.

이미 한 언어의 자막을 올려둔 상태에서도 다른 언어를 추가하는 방식은 같습니다.

처음에는 영상 상세 설정에서 언어를 먼저 추가해야 하는 줄 알았는데 자막 자체를 추가하는 작업은 자막 메뉴에서 바로 진행할 수 있었습니다.

한국어 자막을 넣은 뒤 다른 언어 자막을 추가하는 경우에도 여기서 언어를 하나씩 늘리면 됩니다.

## 2. 원본 동영상 언어는 다른 곳

헷갈렸던 부분은 원본 동영상 언어 설정이었습니다.

이 설정은 자막 메뉴가 아니라 콘텐츠에서 영상을 선택한 뒤 세부정보로 들어가야 합니다. 아래로 내려 더보기를 열면 언어 및 자막 인증 항목에서 동영상의 원본 언어를 지정할 수 있습니다.

즉 자막 언어와 동영상 언어가 같은 설정처럼 보여도 실제로는 역할이 다릅니다.

동영상 언어는 영상에서 기본적으로 사용되는 언어를 유튜브에 알려주는 설정입니다. 유튜브는 이 정보를 자막과 번역 기능을 처리할 때 활용합니다.

자막 파일을 한국어로 올렸다고 해서 영상의 원본 언어 설정까지 자동으로 내가 원하는 값으로 정리됐다고 생각하면 안 됩니다.

## 3. 기존 자막은 그대로 남는다

원본 동영상 언어를 나중에 바꾸는 상황도 생길 수 있습니다.

유튜브 안내에 따르면 원본 언어를 변경해도 이미 게시했거나 임시 저장한 기존 자막이 자동으로 다른 언어로 바뀌는 것은 아닙니다. 앞으로 번역 자막을 만들 때 기준이 되는 원본 언어 쪽에 영향을 주는 설정입니다.

그래서 이미 자막을 여러 개 넣은 뒤 원본 언어가 잘못됐다는 것을 발견했다고 해서 모든 자막을 다시 올릴 필요는 없습니다.

저는 언어 설정을 잘못 건드리면 기존에 넣어둔 자막까지 꼬이는 것 아닌가 걱정했는데 두 기능을 분리해서 생각하니 훨씬 이해하기 쉬웠습니다.

자막 파일의 언어를 관리하는 화면과 영상 자체의 언어 정보를 관리하는 화면이 따로 있다는 것이 핵심입니다.

## 4. 앞으로 올릴 영상은 기본값 설정

같은 언어의 영상을 계속 올린다면 매번 원본 언어를 다시 고르는 것도 번거롭습니다.

유튜브 스튜디오 설정에서 업로드 기본 설정으로 들어가 고급 설정의 동영상 언어를 지정해 두면 이후 업로드할 영상의 기본값으로 사용할 수 있습니다.

한국어 영상이 대부분인 채널이라면 한국어를 기본값으로 정해두고 특별한 영상만 나중에 바꾸는 식이 편합니다.

반대로 영상마다 원본 언어가 자주 달라지는 채널이라면 업로드 후 한 번씩 확인하는 편이 안전합니다. 자막을 여러 언어로 운영할수록 처음에 원본 언어를 정확하게 정해 두는 것이 덜 헷갈립니다.

## 5. 자막과 언어를 따로 생각하기

결국 제가 메뉴를 못 찾았던 이유는 자막과 언어 설정을 하나의 기능이라고 생각했기 때문입니다.

다른 언어 자막을 추가하고 싶을 때는 유튜브 스튜디오의 자막에서 언어 추가로 들어가면 됩니다. 영상이 어떤 언어로 제작됐는지를 정하려면 콘텐츠, 영상 선택, 더보기, 언어 및 자막 인증으로 들어갑니다.

둘을 알고 나면 메뉴 구조가 이상하게 느껴지지 않습니다.

자막을 넣고 나서 언어 설정이 어디 갔는지 한참 찾고 계셨다면 먼저 무엇을 바꾸려는지 구분해 보시면 됩니다. 자막 언어와 원본 동영상 언어는 이름은 비슷하지만 설정 위치도 역할도 다릅니다.

## 6. 자동 자막과 직접 올린 자막

유튜브가 자동으로 만든 자막과 직접 올린 자막도 같은 것으로 생각하기 쉽습니다.

자동 자막이 이미 보이더라도 원하는 번역문이나 직접 검수한 자막을 넣으려면 해당 언어에서 새 자막을 추가해 관리할 수 있습니다. 여러 언어를 운영할 때는 자동으로 생성된 항목과 직접 업로드한 항목이 섞여 보일 수 있으므로 게시 상태와 언어 이름을 같이 확인하는 편이 좋습니다.

특히 자막 파일을 직접 만든 경우에는 업로드가 끝났다는 것만 보고 나오지 않고 실제로 게시 상태인지 확인하는 것이 안전합니다.

언어를 추가한 것과 자막이 시청자에게 공개된 것은 별개일 수 있기 때문입니다. 마지막에 영상 재생 화면에서 해당 언어가 선택되는지 확인하면 작업을 마무리하기 훨씬 편합니다.
