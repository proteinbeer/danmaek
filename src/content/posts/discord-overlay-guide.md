오버워치를 할 때 디스코드는 거의 항상 같이 켜두는 프로그램입니다. 음성 채팅 때문에 필요한 경우가 많아서 디스코드 자체를 종료할 생각은 없었습니다.

그런데 게임을 하다가 뭔가 잘못 눌렀을 때 디스코드 화면이 게임 위에 갑자기 뜨는 일이 있었습니다. 처음에는 그냥 닫고 계속했지만, 정작 게임 중에는 오버레이를 사용할 일이 거의 없었습니다. 결국 저는 디스코드는 그대로 사용하면서 게임 오버레이만 꺼두는 쪽을 선택했습니다.

## 1. 게임 위에 뜨던 화면은 디스코드 게임 오버레이였습니다

디스코드 게임 오버레이는 게임을 종료하거나 창을 전환하지 않고도 채팅, 음성 채널, 알림 같은 기능에 접근할 수 있게 해주는 기능입니다.

기능 자체는 편리할 수 있습니다. 하지만 저처럼 게임 중에 오버레이를 거의 사용하지 않는 경우에는 의도하지 않은 키 입력으로 화면이 나타나는 쪽이 더 불편할 수 있습니다.

디스코드 공식 안내 기준으로 현재 게임 오버레이를 여는 기본 단축키는 ``Shift + ` ``입니다. 키 설정을 변경했다면 다른 조합으로 열릴 수도 있습니다.

## 2. 저는 오버레이 자체를 꺼버렸습니다

디스코드 데스크톱 앱에서 왼쪽 아래 사용자명 옆의 톱니바퀴를 눌러 사용자 설정으로 들어갑니다. 설정에서 게임 오버레이(Game Overlay)를 찾으면 오버레이 활성화 여부를 변경할 수 있습니다.

저는 오버워치에서 오버레이를 일부러 열어 사용할 일이 없었기 때문에 기능을 꺼두는 쪽이 더 편했습니다.

게임 오버레이를 끄는 것과 디스코드 자체를 끄는 것은 다릅니다. 오버레이는 게임 화면 위에 디스코드 인터페이스를 표시하는 기능이므로, 음성 채널을 이용하려면 디스코드 앱은 그대로 실행해두면 됩니다.

## 3. 모든 게임에서 끌 필요는 없습니다

오버레이가 필요한 게임도 있다면 전체 기능을 무조건 꺼둘 필요는 없습니다. 특정 게임에서만 오버레이가 거슬린다면 해당 게임에 대해서만 비활성화하는 방법도 있습니다.

저처럼 오버레이를 아예 사용하지 않는다면 전체 기능을 끄는 편이 간단하고, 다른 게임에서는 사용하는 사람이라면 문제가 되는 게임만 따로 끄는 편이 낫습니다.

디스코드 역시 오버레이 사용 중 랙이나 게임 충돌 등 문제가 발생하는 경우 해당 게임에서 오버레이를 비활성화해볼 것을 공식 도움말에서 안내하고 있습니다.

## 4. 단축키만 바꾸는 방법도 있습니다

오버레이 기능은 필요한데 게임 중 실수로 열리는 것만 문제라면 기능 전체를 끄는 대신 단축키를 바꾸는 방법도 있습니다.

디스코드 키 설정에서는 오버레이 관련 단축키를 변경할 수 있습니다. 게임에서 자주 사용하는 키와 겹치지 않는 조합으로 바꾸면 실수로 호출되는 일을 줄일 수 있습니다.

오버레이를 전혀 사용하지 않는다면 꺼두고, 가끔 사용한다면 단축키를 바꾸거나 특정 게임에서만 끄면 됩니다.

## 5. 필요 없는 기능이라면 켜둘 이유도 없었습니다

처음에는 디스코드를 게임할 때 같이 사용하니 오버레이도 그냥 켜두고 있었습니다. 하지만 실제로 오버워치를 하면서 오버레이 기능을 활용한 적은 거의 없고, 잘못 눌러 화면이 나타나는 쪽이 더 신경 쓰였습니다.

그래서 지금은 필요한 디스코드는 그대로 사용하면서 오버레이만 꺼두고 있습니다.

오버워치뿐 아니라 다른 게임에서도 디스코드 화면이 갑자기 게임 위에 나타나 불편하다면 디스코드 전체를 종료하기 전에 게임 오버레이 설정부터 확인해볼 만합니다. 반대로 게임 중 채팅이나 음성 상태를 화면에서 확인하는 사람이라면 기능을 완전히 끄기보다 단축키나 게임별 설정을 조정하는 편이 더 적합합니다.
