WOL은 네트워크에서 매직 패킷을 보내 절전 중이거나 꺼진 PC를 깨우는 기능입니다. 설정 화면 하나만 켜면 될 것 같지만 메인보드 전원과 랜카드, 윈도우가 모두 조건을 맞춰야 해서 한 곳만 빠져도 아무 반응이 없습니다.

가장 먼저 볼 것은 PC를 끈 뒤에도 랜포트에 대기 전력이 남아 있는지입니다. 완전 종료 순간 랜카드 전원이 같이 사라지면 네트워크 패킷을 받을 장치가 없으므로 운영체제 설정만 계속 바꿔도 켜지지 않습니다.

## 1. 바이오스 전원 설정

메인보드 바이오스에서 WOL이나 PCIe 장치 깨우기와 관련된 항목을 확인합니다. 제조사마다 이름이 다르고 절전 관련 옵션과 묶여 있을 수 있습니다.

전력 절약 기능이 종료 상태에서 랜카드 전원까지 끄는 경우도 있습니다. 설정을 바꾼 뒤 PC를 완전히 종료하고 랜포트 표시등이 남는지 확인합니다.

## 2. 랜카드 매직 패킷

윈도우 장치 관리자에서 유선 랜카드의 고급 설정과 전원 관리 항목을 확인합니다. 매직 패킷으로 깨우기 기능이 비활성화돼 있으면 네트워크 패킷을 받아도 시스템을 깨우지 못합니다.

절전 모드에서만 필요한 옵션과 완전 종료에서 필요한 조건은 다를 수 있습니다. 메인보드와 랜카드가 어느 전원 상태까지 지원하는지 제품 문서도 확인할 만합니다.

## 3. 유선에서 먼저 시험

WOL은 가능하면 유선 이더넷으로 먼저 구성하는 편이 좋습니다. 무선에서 깨우는 기능은 하드웨어와 드라이버 지원 범위가 더 제한적입니다.

같은 집 안 네트워크에서 매직 패킷을 보내 먼저 동작을 확인합니다. 내부망에서도 실패하는 상태에서 외부 인터넷 설정까지 추가하면 원인만 복잡해집니다.

## 4. MAC 주소 확인

매직 패킷은 대상 랜카드의 MAC 주소를 기준으로 보냅니다. 와이파이 MAC이나 가상 어댑터 주소를 잘못 넣으면 같은 PC라도 반응하지 않습니다.

윈도우에서 실제 유선 랜카드 주소를 확인해 앱과 도구에 정확히 입력합니다. USB 랜카드와 도킹을 바꿨다면 MAC 주소도 달라질 수 있습니다.

## 5. 외부 WOL은 별도 문제

집 밖에서 WOL을 사용하려면 공유기와 VPN, 포트 전달, ARP 유지 같은 추가 조건이 생길 수 있습니다. 공유기마다 브로드캐스트 전달 지원 방식이 달라 단순 포트포워딩이 항상 잘 되는 것은 아닙니다.

보안을 생각하면 집 VPN에 먼저 연결한 뒤 내부망에서 WOL을 보내는 방식이 더 관리하기 쉬울 수 있습니다. 외부 기능은 내부 WOL이 확실히 된 뒤 추가하시는 편이 좋습니다.

WOL이 안 될 때는 프로그램보다 전원이 꺼진 뒤 랜카드가 살아 있는지를 먼저 보시면 됩니다. 하드웨어가 패킷을 받을 준비가 돼 있어야 윈도우와 앱 설정도 의미가 있습니다.

같은 내부망에서 성공하는 상태를 만든 뒤 외부 접속을 붙이면 문제 범위를 단계적으로 줄일 수 있습니다. 처음부터 포트포워딩까지 만지는 것보다 훨씬 확인하기 쉽습니다.

빠른 시작 설정과 시스템 종료 방식이 WOL 동작에 영향을 주는 PC도 있습니다. 절전에서는 되는데 완전 종료에서만 안 된다면 같은 설정을 반복하기보다 전원 상태별 지원 차이를 확인해보는 편이 좋습니다.

## 6. 내부 WOL부터 성공시켜야 하는 이유

확인할 항목이 많아 보여도 시작점은 같은 집 안에서 매직 패킷이 동작하는지입니다. 그다음 절전과 종료 상태를 각각 비교하면 문제 구간이 생각보다 빠르게 좁혀집니다. 내부에서도 안 되면 외부 포트보다 BIOS와 랜카드 대기 전원을 먼저 봐야 함이라는 점 때문에 눈에 보이는 증상만 따라가면 엉뚱한 설정을 만지기 쉽습니다.

특히 관리자 페이지를 인터넷에 그대로 노출하는 것은 피하시는 편이 좋습니다. 먼저 외부에서는 공유기 전달 방식과 공인 IP 구조 확인해서 결과가 어떻게 바뀌는지 확인하십시오. 같은 문제가 계속되면 CGNAT 환경이면 VPN이나 중계 방식이 더 현실적일 수 있음하면서 더 넓은 구간을 확인하면 됩니다.

이 글의 증상에서는 같은 집 안에서 매직 패킷이 동작하는지이 가장 재현성이 높은 확인값입니다. 한 번에 여러 설정을 바꾸지 마시고 외부에서는 공유기 전달 방식과 공인 IP 구조 확인한 결과부터 비교하시면 같은 문제가 생겨도 다시 처음부터 점검할 필요가 없습니다.

노트북은 데스크톱과 달리 완전 종료 상태에서 WOL을 지원하지 않는 모델도 있습니다. 절전에서는 잘 깨어나는데 종료 상태에서는 전혀 반응하지 않는다면 메인보드 고장으로 보기 전에 제품 문서에서 지원 범위를 확인하시는 편이 좋습니다.
