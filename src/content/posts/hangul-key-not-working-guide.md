## 1. 입력 언어 확인

작업 표시줄 오른쪽 아래에 한국어 입력기가 선택돼 있는지 확인하시면 됩니다. 영어 입력기로 바뀌었다면 한국어로 다시 선택하시면 되죠.

## 2. 단축키로 전환

윈도우 키와 스페이스바를 누르면 설치된 입력 언어를 전환할 수 있습니다. 한영키가 반응하지 않을 때 임시로 쓰기 좋고요.

## 3. 한국어 입력기 다시 확인

설정, 시간 및 언어, 언어 및 지역에서 한국어가 정상적으로 설치돼 있는지 확인하시면 됩니다.

## 4. 특정 프로그램만 문제라면

다른 프로그램에서는 한영 전환이 되는데 한 프로그램에서만 안 된다면 해당 프로그램을 다시 실행하거나 관리자 권한 설정을 확인해보시는 것이 좋습니다.
