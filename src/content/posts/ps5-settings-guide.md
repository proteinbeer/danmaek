PS5를 처음 켜면 기본 설정만으로도 잘 작동하지만, 화질과 반응속도는 몇 가지 설정으로 더 끌어올릴 수 있습니다. TV가 지원하는 기능을 제대로 켜두지 않으면 4K와 부드러운 프레임을 다 살리지 못하죠.

모니터나 TV의 성능이 좋을수록 설정의 중요성이 커집니다. 화면·성능 위주로 PS5에서 확인하고 조정하면 좋은 설정을 아래에 정리했습니다.

## 1. 영상 출력 설정 확인

먼저 PS5가 제대로 연결되고 있는지 확인합니다.

- **설정 → 화면 및 영상 → 비디오 출력**으로 이동합니다.
- **해상도**가 화면 해상도(4K 또는 1440p)와 일치하는지 확인합니다.
- TV가 HDMI 2.1을 지원한다면 **HDR 자동**과 높은 주사율 출력 옵션이 활성화됩니다.

HDMI 포트도 TV의 **HDMI 2.1(게임 전용) 포트**에 연결하는 것이 좋습니다. 장비를 인식하지 못하면 최적 옵션이 비활성화되기 때문입니다.

## 2. VRR(가변 주사율) 켜기

화면 주사율을 프레임에 맞춰 변화시키는 **VRR**은 끊김을 크게 줄여줍니다.

- **설정 → 화면 및 영상 → 비디오 출력 → VRR** 항목을 **자동 또는 항상**으로 설정합니다.
- VRR을 쓰려면 TV나 모니터가 **HDMI 2.1 VRR**과 게임 모드를 지원해야 합니다.
- 지원 TV에서는 프레임 하락 구간이 있어도 화면이 덜 버벅입니다.

VRR은 설정 화면에서 **디스플레이 정보 확인**을 눌러 지원 여부를 바로 알 수 있습니다. 해당 항목이 회색이면 기기 문제보다 연결 포트를 먼저 점검해보시기 바랍니다.

## 3. 120Hz 출력 활용

신작 게임에서 120FPS를 지원한다면 120Hz 출력을 활성화할 때입니다.

- **설정 → 화면 및 영상 → 비디오 출력 → 120Hz 출력**을 **자동**으로 둡니다.
- 120Hz 모드가 기본인 게임은 그대로 켜지고, 게임 내 설정에서 **성능 모드(120Hz)**를 고르는 타이틀도 있습니다.
- 120Hz를 제대로 쓰려면 TV가 **HDMI 2.1 120Hz**를 지원하는 것이 이상적입니다.

케이블도 HDMI 2.1(울트라 하이 스피드) 인증 제품을 쓰는 것이 좋습니다. 저속 케이블은 신호가 불안정해 120Hz 모드가 켜지지 않는 원인이 되죠.

## 4. 게임별 성능·해상도 모드

화면과 프레임은 게임마다 우선순위가 다릅니다. PS5는 게임 단위로 설정을 조정할 수 있습니다.

- **설정 → 화면 및 영상 → 게임에 적용된 설정**에서는 **게임 화면 모드 오버라이드**를 켤 수 있습니다.
- 대부분의 최신 게임은 **성능 모드(60FPS)**와 **해상도 모드(4K)** 중 하나를 제공합니다.
- 빠른 반응이 중요한 때는 성능 모드, 깊은 그래픽을 감상하고 싶을 때는 해상도 모드가 어울립니다.

게임 내 옵션에서도 바로 바꿀 수 있습니다. 타격감이 중요한 액션·슈팅은 프레임 우선이 유리하고, 어드벤처는 화질 우선도 충분합니다.

## 5. 기본 화질·컨트롤러 설정

외부 기능 없이 체감을 높일 수 있는 기본 설정들입니다.

- **설정 → 화면 및 영상 → 화면**에서 **HDR 자동**과 콘텐츠 자동 재생 설정을 확인합니다.
- **설정 → 액세서리 → 컨트롤러(듀얼센스)**에서는 진동 강도와 **트리거 효과 크기**를 조절할 수 있습니다.
- 배터리를 아끼고 싶다면 **컨트롤러 소등 & 진동** 옵션을 조정해 조명을 줄이는 것도 방법입니다.

전원이 중요한 상황이라면 컨트롤러 마이크를 무음으로 두어도 조금은 절약됩니다. 게임 장르에 맞는 진동 강도를 찾는 것이 그립감과 몰입감을 결정합니다.

## 6. 절전과 자동 업데이트 정리

마지막으로 시스템 관리 설정을 챙겨둡니다.

- **설정 → 시스템 → 전원 절약**에서 **휴식 모드** 타이머를 정해 전력 소비를 관리합니다.
- 휴식 모드에서 **업데이트 자동 설치**를 켜두면 새 게임과 시스템 업데이트가 편하게 준비되어 있습니다.
- **게임 자동 업데이트**와 **번들 콘텐츠 자동 업데이트**는 게임을 자주 하는 분께 편리합니다.

휴식 모드는 대기상태보다 전력을 더 쓰므로, 장시간 안 쓸 땐 완전히 끄는 것도 좋습니다. 업데이트와 절전의 균형은 생활 패턴에 맞추면 됩니다.
