USB 마이크를 새로 연결했는데 녹음 소리가 지나치게 작으면 마이크 성능이 부족하다고 생각하기 쉽습니다.

하지만 윈도우 입력 볼륨과 앱 안의 게인, 마이크 거리 중 하나만 어긋나도 충분히 큰 마이크가 작게 녹음될 수 있죠.

반대로 볼륨을 무작정 100으로 올리면 배경 잡음까지 함께 커질 수 있습니다.

소리를 크게 만드는 것보다 적절한 입력 레벨을 만드는 순서가 중요합니다.

## 1. 윈도우 입력 볼륨 확인

설정, 시스템, 소리, 입력에서 현재 사용 중인 USB 마이크를 선택하면 입력 볼륨을 확인할 수 있습니다.

여러 마이크가 연결돼 있다면 노트북 내장 마이크가 선택돼 있지 않은지도 먼저 보셔야 합니다.

마이크 테스트를 실행하면서 평소 말하는 목소리로 입력 막대가 움직이는지 확인하시면 됩니다.

거의 움직이지 않는다면 앱 설정을 만지기 전에 윈도우 단계에서 이미 입력이 작은 상태일 수 있습니다.

일부 USB 마이크는 제조사 프로그램이나 본체 다이얼로 게인을 따로 조절합니다.

윈도우 볼륨과 하드웨어 게인이 둘 다 낮으면 소리가 매우 작게 들어갈 수 있죠.

## 2. 게인과 볼륨은 같은 역할이 아니다

게인은 마이크에서 들어오는 아주 작은 신호를 초기에 얼마나 증폭할지 정합니다.

볼륨은 이미 들어온 신호를 재생하거나 전달하는 크기를 조절하는 개념에 더 가깝습니다.

게인을 너무 낮게 두고 나중에 프로그램에서 볼륨만 크게 올리면 목소리와 함께 바닥 잡음도 커질 수 있습니다.

가능하면 마이크 가까운 단계에서 적절한 신호를 확보하는 편이 좋습니다.

USB 마이크에 게인 다이얼이 있다면 말을 하면서 천천히 올리고, 큰 목소리에서 소리가 찢어지지 않는 지점을 찾으시면 됩니다.

최대값이 좋은 게 아니라 평소 목소리가 충분히 들어오는 값이 좋습니다.

## 3. 마이크와 입 사이 거리

콘덴서 마이크는 책상 한쪽 멀리 놓고 게인만 올리면 방 소리와 키보드 소리까지 많이 들어올 수 있습니다.

가능하면 입과 마이크 사이 거리를 줄이고 게인을 낮추는 방식이 더 깨끗한 결과를 만듭니다.

마이크가 어느 방향의 소리를 받는지도 확인하셔야 합니다.

옆면을 향해 말해야 하는 마이크에 위쪽으로 말하거나 반대로 세워두면 소리가 작아질 수 있죠.

제품 설명에서 수음 방향을 확인하고 로고나 표시가 있는 면을 기준으로 배치하시면 좋습니다.

의외로 방향을 바꾸는 것만으로 게인을 크게 올리지 않아도 소리가 충분해지는 경우가 있습니다.

## 4. 디스코드와 녹음 프로그램 설정

디스코드, 줌, 방송 프로그램은 윈도우와 별도로 입력 장치와 볼륨을 관리합니다.

윈도우에서는 정상인데 특정 프로그램에서만 작다면 앱 안에서 다른 마이크가 선택됐거나 입력 볼륨이 낮은지 확인하셔야 합니다.

자동 입력 감도와 자동 게인 기능이 목소리를 예상과 다르게 조절하기도 합니다.

문제가 있을 때는 자동 기능을 잠시 끄고 수동으로 입력 레벨을 맞춰보는 편이 원인을 찾기 쉽습니다.

여러 프로그램을 동시에 켜고 테스트하면 각 프로그램의 보정이 섞여 판단이 어려울 수 있습니다.

먼저 윈도우 녹음기처럼 단순한 앱에서 기본 소리를 확인한 뒤 사용하려는 프로그램으로 넘어가시면 됩니다.

## 5. USB 허브와 전원 확인

일부 마이크는 USB 허브나 도킹 장치를 거치면 전원이 불안정해지거나 장치가 제대로 초기화되지 않을 수 있습니다.

소리가 지나치게 작거나 연결이 반복된다면 본체 USB 포트에 직접 연결해 비교해보시면 됩니다.

케이블 교체도 간단한 확인 방법입니다.

충전만 되는 케이블이나 상태가 나쁜 케이블을 사용하면 데이터 연결이 불안정할 수 있습니다.

## 6. 큰 소리보다 깨끗한 소리가 먼저

마이크를 잘 설정한다는 것은 입력 막대를 항상 끝까지 채우는 것이 아닙니다.

평소 목소리는 충분히 크게 들어오고, 웃거나 크게 말했을 때도 소리가 찢어지지 않는 여유를 남기는 것이 중요하죠.

제가 설정한다면 마이크 위치를 먼저 가까이 잡고, 하드웨어 게인, 윈도우 입력 볼륨, 앱 입력 볼륨 순서로 확인하겠습니다.

이 순서로 맞추면 소리를 키우기 위해 잡음까지 함께 키우는 실수를 줄일 수 있습니다.

## 7. 테스트 녹음으로 기준 만들기

설정을 바꿀 때마다 같은 문장을 같은 거리에서 녹음해보시면 무엇이 달라졌는지 비교하기 쉽습니다.

귀로만 실시간 모니터링하면 순간적인 볼륨 차이에 속기 쉬워 실제 녹음 파일을 남기는 편이 더 정확합니다.

목소리가 충분히 크면서 배경 소음이 지나치게 올라오지 않는 지점을 찾으면 그 값을 기준으로 저장하시면 됩니다.

마이크 설정은 숫자보다 반복 가능한 기준을 만드는 것이 중요합니다.
