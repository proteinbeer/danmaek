같은 네트워크에서 두 기기가 같은 IP 주소를 사용하면 한쪽이 갑자기 끊기거나 두 기기가 번갈아 연결되는 이상한 증상이 생길 수 있습니다. 요즘 공유기는 DHCP로 주소를 자동 배분하므로 흔하지 않지만 수동 IP와 오래된 장비가 섞이면 여전히 발생합니다.

중요한 건 어느 기기가 잘못됐는지 추측하는 것이 아니라 중복 주소가 왜 생겼는지 찾는 것입니다. 특히 PC에 직접 넣은 고정 IP가 공유기의 DHCP 자동 배분 범위 안에 들어가 있으면 같은 문제가 다시 생길 가능성이 큽니다.

1. 자동 주소와 수동 주소

DHCP는 공유기가 연결된 기기에 사용 가능한 주소를 자동으로 나눠주는 방식입니다. 반면 PC나 프린터에 직접 고정 IP를 넣으면 공유기가 그 주소를 다른 기기에 배정하지 말아야 한다는 사실을 모를 수 있습니다.

공유기가 자동 배분하는 범위 안의 주소를 수동으로 쓰면 나중에 다른 기기와 겹칠 여지가 생깁니다. 고정 주소를 쓸 거라면 DHCP 범위 밖을 쓰거나 예약 기능을 사용하는 편이 안전합니다.

2. 충돌 직후 할 일

문제가 생긴 PC에서 현재 IP 주소와 기본 게이트웨이를 먼저 기록합니다. 바로 모든 설정을 초기화하면 어떤 주소가 충돌했는지 단서가 사라질 수 있습니다.

자동 설정을 쓰는 PC라면 어댑터를 다시 연결해 새 DHCP 주소를 받게 할 수 있습니다. 새 주소를 받은 뒤 문제가 사라진다면 수동 주소 장비나 오래된 임대 정보를 공유기 목록에서 확인합니다.

3. 프린터와 NAS 확인

가정에서 충돌을 자주 만드는 장비는 프린터와 NAS처럼 항상 같은 주소를 쓰려고 설정한 기기입니다. 설치 당시에는 비어 있던 주소라도 공유기 교체 뒤 DHCP 범위가 달라지면서 겹칠 수 있습니다.

공유기 관리 화면의 연결 장치 목록에서 동일 주소나 비슷한 이름이 반복되는지 확인합니다. 장비마다 직접 주소를 넣기보다 공유기에서 MAC 주소를 기준으로 DHCP 예약을 걸어두면 관리가 훨씬 편해집니다.

4. 무작위 MAC 주의

스마트폰과 노트북은 개인정보 보호를 위해 와이파이마다 무작위 MAC 주소를 사용할 수 있습니다. DHCP 예약을 했는데도 기기가 다른 주소를 받는다면 예약한 MAC 주소와 실제 연결에 사용된 주소가 같은지 확인하셔야 합니다.

집 네트워크에서 특정 기기를 항상 같은 IP로 쓰려는 목적이라면 해당 네트워크에서 사용하는 MAC 방식까지 함께 확인해야 합니다. 예약만 걸었다고 무조건 고정되는 것은 아닙니다.

5. 재발을 막는 구성

일반 PC와 스마트폰은 DHCP 자동 할당으로 두고 NAS와 프린터처럼 주소가 고정돼야 하는 장비만 DHCP 예약으로 관리하는 구성이 단순합니다. 직접 고정 IP를 많이 넣을수록 나중에 공유기 교체나 주소 대역 변경 때 관리할 것이 늘어납니다.

IP 충돌은 인터넷 속도의 문제가 아니라 주소 관리 문제입니다. 한 번 해결한 뒤에는 DHCP 범위와 예약 목록을 정리해두는 것이 같은 오류를 반복하지 않는 가장 좋은 방법입니다.

주소 예약을 정리할 때 장비 이름도 함께 알아보기 쉽게 바꿔두면 다음 문제 해결이 편합니다. 공유기 목록에 알 수 없는 기기 이름만 가득하면 충돌이 다시 생겼을 때 어느 장비인지 찾는 데 시간이 더 걸립니다.

IP 충돌은 한 번 재부팅해서 사라졌다고 끝난 문제가 아닐 수 있습니다. 중복을 만든 수동 주소나 예약 규칙을 정리해야 같은 상황이 다시 생기지 않습니다.

공유기를 교체한 뒤 처음 충돌이 생겼다면 예전 장비에서 쓰던 고정 IP 설정을 가장 먼저 확인할 만합니다. 새 공유기의 자동 배분 범위가 이전 장비와 다르면 오래된 수동 값이 갑자기 문제를 만들 수 있습니다.

6. 충돌을 다시 만들지 않는 주소 관리

확인할 항목이 많아 보여도 시작점은 공유기 DHCP 예약 목록과 수동 IP 장치입니다. 그다음 같은 주소를 쓰는 MAC 주소가 없는지 확인하면 문제 구간이 생각보다 빠르게 좁혀집니다. 충돌은 두 장치가 켜지는 시점에 따라 간헐적으로 나타날 수 있음이라는 점 때문에 눈에 보이는 증상만 따라가면 엉뚱한 설정을 만지기 쉽습니다.

특히 재부팅만 반복하는 것은 피하시는 편이 좋습니다. 먼저 예약과 수동 주소의 범위를 겹치지 않게 정리해서 결과가 어떻게 바뀌는지 확인하십시오. 같은 문제가 계속되면 새 프린터나 NAS를 추가한 직후라면 최근 장치부터 확인하면서 더 넓은 구간을 확인하면 됩니다.
