같은 공유기에 연결된 PC인데 파일 탐색기의 네트워크 목록에 상대 컴퓨터가 보이지 않을 때가 있습니다. 이때 공유 폴더가 삭제됐다고 생각하기 쉽지만 실제로는 검색 기능만 꺼져 있고 공유 자체는 살아 있는 경우도 많습니다.

먼저 상대 PC의 이름이나 IP 주소로 직접 접근해보시면 됩니다. 직접 접근은 되는데 네트워크 목록에만 안 보인다면 파일 공유 권한보다 윈도우의 검색 서비스와 네트워크 프로필을 보는 편이 맞습니다.

## 1. 개인 네트워크 설정

집이나 신뢰할 수 있는 내부망에서는 네트워크 프로필이 개인으로 설정돼 있어야 검색과 공유 기능을 사용하기 편합니다. 공용 프로필은 카페나 호텔처럼 다른 기기를 신뢰하기 어려운 환경을 전제로 하므로 검색 관련 방화벽 규칙이 더 제한됩니다.

현재 연결의 네트워크 속성을 열어 개인 프로필인지 확인합니다. 회사나 학교처럼 관리 정책이 있는 환경에서는 임의로 바꾸기 전에 관리자 설정을 우선해야 합니다.

## 2. 검색 기능 두 가지

고급 공유 설정에서 네트워크 검색과 파일 및 프린터 공유가 켜져 있는지 확인합니다. 둘은 비슷해 보이지만 하나는 다른 장치를 찾아 목록에 보여주는 기능이고 다른 하나는 실제 파일과 프린터 접근을 허용하는 기능입니다.

검색만 켜고 공유가 꺼져 있으면 PC는 보여도 폴더가 열리지 않을 수 있습니다. 반대로 공유가 살아 있어도 검색이 꺼져 있으면 목록에는 안 보이면서 주소를 직접 입력하면 접속되는 상황이 생깁니다.

## 3. 검색 서비스 점검

윈도우의 Function Discovery Provider Host와 Function Discovery Resource Publication 서비스는 네트워크 장치 발견에 관여합니다. 해당 서비스가 중지돼 있으면 같은 공유기에 있어도 파일 탐색기 목록에서 PC가 사라질 수 있습니다.

서비스를 무조건 자동으로 바꾸기보다 현재 중지돼 있는지와 재시작 후 목록이 달라지는지 확인합니다. 시스템 최적화 프로그램을 사용한 뒤부터 문제가 생겼다면 이런 서비스가 비활성화된 경우도 있습니다.

## 4. IP로 직접 접근

파일 탐색기 주소창에 상대 PC의 IP 주소를 이용해 직접 접근해보면 검색 문제와 공유 문제를 나눌 수 있습니다. 직접 접속까지 실패한다면 방화벽, 공유 권한, 두 PC의 주소 대역을 함께 확인해야 합니다.

두 PC가 각각 다른 공유기에 물려 있거나 게스트 와이파이의 기기 격리가 켜져 있으면 같은 집에서도 서로 보이지 않을 수 있습니다. 이때 윈도우만 계속 만져서는 해결되지 않습니다.

## 5. SMB는 무작정 낮추지 않기

오래된 NAS나 구형 장비 때문에 검색이 안 된다고 SMB 1 기능부터 켜라는 방법이 자주 보입니다. SMB 1은 오래된 방식이고 보안상 이유로 기본 비활성화된 환경이 많으므로 최신 PC끼리 공유하는 문제에서는 우선순위가 아닙니다.

최신 PC끼리라면 개인 네트워크, 검색 서비스, 방화벽, 공유 권한을 먼저 확인합니다. 구형 장비 호환이 정말 필요한 경우에만 제조사 문서를 보고 별도로 판단하는 편이 안전합니다.

공유가 정상으로 돌아온 뒤에도 모든 폴더를 네트워크에 공개할 필요는 없습니다. 필요한 폴더만 권한을 정하고 계정 암호를 사용하면 편의성을 유지하면서 불필요한 노출을 줄일 수 있습니다.

네트워크 목록은 편의를 위한 발견 기능이고 실제 공유 연결 그 자체는 아닙니다. 목록에 안 보인다는 현상과 폴더 접속이 안 된다는 현상을 나눠보면 해결 순서가 훨씬 단순해집니다.

PC 이름을 바꾼 직후에는 재부팅과 검색 갱신에 시간이 필요한 경우도 있습니다. 이름만 바꾸고 바로 목록을 확인했다면 상대 PC에서 직접 주소로 접근한 뒤 다시 검색 결과를 보는 편이 좋습니다.

## 7. 목록보다 실제 접근이 중요한 이유

실전에서는 상대 PC의 이름과 IP 주소로 직접 접근되는지만 확인해도 다음 행동이 훨씬 명확해집니다. 탐색기 목록 표시와 공유 기능을 분리해서 테스트하면 장비 문제인지 설정 문제인지도 나누기 쉬워집니다. 결국 직접 접근은 되는데 목록만 비면 검색 서비스 쪽 문제로 좁힐 수 있음이라는 구조를 이해하는 것이 핵심입니다.

반대로 오래된 공유 프로토콜을 다시 켜는 것은 원인을 가려버릴 수 있습니다. 우선 개인 네트워크 프로필과 방화벽 공유 규칙 점검하고 한 번 더 재현해 보십시오. 이후에도 해결되지 않을 때 이름으로만 실패하면 이름 해석과 장치 이름 등록 상태 확인하면 어디까지 점검해야 할지 판단하기 편합니다.
