Windows 파일 탐색기의 ’네트워크’에서 다른 PC가 사라졌다고 공유 폴더까지
없어진 것은 아닙니다. 먼저 상대 PC가 실제로 통신 가능한지 확인하면 검색
기능 문제와 공유 권한 문제를 나눌 수 있습니다.

## PC 이름 대신 IP로 접속합니다

상대 PC가 192.168.0.30이라면 탐색기 주소창에 `\\192.168.0.30`을
입력합니다. 공유 폴더가 열린다면 파일 공유 자체는 살아 있고 네트워크
검색 기능을 확인할 차례입니다. IP로도 열리지 않으면 검색 기능만의 문제는
아닙니다.

## 같은 네트워크인지 확인합니다

두 PC의 ipconfig에서 IPv4와 기본 게이트웨이를 비교합니다. 한쪽이 게스트
와이파이나 별도 라우터에 연결되어 있다면 서로 발견되지 않을 수 있습니다.

## Windows 네트워크 프로필을 봅니다

신뢰하는 집 네트워크에서 공유를 사용할 때는 네트워크 프로필이 공용으로
되어 있지 않은지 확인합니다. 개인 네트워크로 설정한 뒤 네트워크 검색과
파일·프린터 공유 상태를 봅니다.

필요하면 Function Discovery Provider Host와
Function Discovery Resource Publication 같은 검색 관련 서비스의 상태도
확인합니다. 방화벽 전체를 끄기보다 현재 프로필에서 검색과 파일 공유
규칙이 허용되어 있는지 보는 편이 낫습니다.

PC는 보이는데 특정 폴더에서 액세스 거부가 뜬다면 이제 검색 문제가 아니라
공유 권한과 NTFS 권한을 확인해야 합니다.

가장 좋은 첫 테스트는 IP 직접 접속입니다. 이 결과 하나로 ’PC 검색
문제’와 ’실제 파일 공유 연결 문제’를 빠르게 나눌 수 있습니다.
