스팀에서 워독스를 눌렀는데 게임 창이 뜨지 않거나 실행 중 표시가 바로 사라진다면 그래픽 설정까지 갈 수 없습니다. 이 경우 게임 파일과 커널 수준 안티 치트 실행 단계부터 확인하는 편이 빠릅니다.

## 1. 업데이트 확인

얼리 액세스 초기는 짧은 간격으로 핫픽스가 올라올 수 있습니다. 이전 플레이테스트 파일과 새 실행 파일이 맞지 않으면 시작 단계에서 문제가 생길 수 있습니다.

스팀 다운로드 대기열을 확인하고 워독스 업데이트를 끝까지 받은 뒤 윈도우를 한 번 재부팅합니다. 새 안티 치트 구성 요소도 재부팅 뒤 정상적으로 올라올 수 있습니다.

## 2. 무결성 검사

스팀 설치 파일 메뉴의 무결성 검사는 누락되거나 손상된 파일을 필요한 만큼 다시 받을 수 있는 기본 점검입니다.

게임 전체를 지우기 전에 먼저 실행할 가치가 큽니다. 검사 뒤에는 여러 설정을 동시에 바꾸지 말고 기본 상태에서 다시 실행합니다.

## 3. 오버레이와 입력 프로그램

안티 치트는 게임 프로세스에 접근하는 오버레이, 매크로, 특수 입력기와 충돌할 수 있습니다.

윈도우 보안 기능을 끄기보다 먼저 필요하지 않은 주변 프로그램을 종료하고 비교하는 편이 안전합니다. 정상 실행되면 하나씩 다시 켜시면 됩니다.

## 4. 권한 수준

스팀은 일반 권한인데 게임만 관리자 권한으로 강제하면 프로그램 사이 권한 수준이 달라질 수 있습니다.

테스트할 때는 스팀과 게임을 같은 권한 수준으로 두는 편이 좋습니다. 인터넷 해결법을 한꺼번에 적용하지 않는 것이 중요합니다.

## 5. 윈도우와 드라이버

최소 운영체제는 윈도우 10이고 권장은 윈도우 11입니다. 오래된 그래픽 드라이버나 윈도우 빌드는 최신 안티 치트와 충돌할 수 있습니다.

업데이트 뒤부터 문제가 시작됐다면 최신이라는 이유만으로 원인을 배제하지 않습니다. 날짜를 기준으로 증상이 언제 생겼는지 확인하시면 됩니다.

## 6. 재설치 기준

무결성 검사와 업데이트로 해결되지 않을 때 게임 재설치를 고려합니다. 블루스크린까지 발생한다면 계속 실행을 반복하기보다 먼저 알려진 안티 치트 문제와 핫픽스를 확인합니다.

저라면 업데이트, 무결성 검사, 백그라운드 프로그램 정리, 윈도우 상태 순서로 범위를 좁히겠습니다. 실행 오류를 일반 크래시와 나눠서 보는 것이 좋습니다.
