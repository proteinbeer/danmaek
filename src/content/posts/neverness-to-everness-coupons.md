이환(Neverness to Everness)은 호타 스튜디오가 개발하고 퍼펙트 월드가 서비스하는 어반 판타지 오픈월드 RPG입니다. 이상 헌터가 되어 도시에서 벌어지는 사건을 해결하는 세계관으로, PC와 모바일을 오가며 플레이할 수 있습니다.

이환 코드는 방송과 이벤트에서 자주 나오며, 유효 기간이 몇 주 안팎으로 짧은 편입니다. 새 코드가 보이면 바로 입력해두는 습관이 좋죠.

## 1. 지금 사용 가능한 최신 쿠폰

9월 4일 기준으로 확인된 이환 사용 가능 리딤코드는 다음과 같습니다. 표의 코드를 게임 내 교환 코드 메뉴에서 입력하면 됩니다.

| 쿠폰 코드 | 보상 |
| --- | --- |
| ZANKOU0819 | 환석 30, 폰즈 50,000, 비틀 코인 30,000 |
| COMEBACK | 기만의 주사위 1개 |
| NTEGIFT | 환석 50, 라이징 헌터 가이드 5, 연한 염료 5 |
| NTEKokushi | 폰즈 30,000, 비틀 코인 30,000 |
| NTEMusou | 폰즈 10,000, 비틀 코인 10,000 |

대부분의 이환 코드는 별도 기한 표시 없이 사용할 수 있지만 (게임 내 교환 코드)

이환은 게임 내에서 바로 코드를 입력합니다. PC와 모바일 모두 동일한 방식입니다.

1. 이환을 실행합니다.
2. ESC 키를 눌러 메뉴를 열고, 우측 상단의 ··· 아이콘을 클릭합니다.
3. [교환 코드]를 선택하고 코드를 입력한 뒤 확인을 누릅니다.
4. 게임 내 우편함에서 보상을 수령합니다.

코드 입력 메뉴는 튜토리얼 진행 후에 열립니다. 메뉴가 보이지 않는다면 메인 스토리를 조금 진행해주시기 바랍니다.

## 3. 계정당 1회 사용과 보상 수령

이환 리딤코드는 계정당 1회만 사용할 수 있습니다. 같은 계정에서 두 번째로 입력하면 이미 사용한 코드라는 안내가 나옵니다.

보상은 입력 즉시 지급되지 않고 우편함으로 도착합니다. 모두 수령을 눌러 한 번에 챙기는 편이 좋죠.

## 4. 방송 코드의 짧은 유효 기간

1.3 프리뷰 방송에서 공개된 FOGDENGAME, EYEOFDELUSION, SUMMERTIME은 8월 11일에 이미 만료됐습니다. 출시 기념 코드 WELCOMETONTE도 8월 19일을 마지막으로 사용이 끝났습니다.
