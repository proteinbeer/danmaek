봄바나나는 출시 직후 빠르게 패치가 이어지고 있습니다. 9월 3일 1점0점1 핫픽스에서 음성 채팅 문제를 수정했고, 9월 10일 1점0점2에서는 매치메이킹과 난도 조정, 컨트롤러 UI, 로비 코드, 음성 시스템 개선이 들어갔습니다.

특히 음성 채팅 문제는 다른 협동 게임보다 치명적입니다. 역할 자체가 소리를 듣거나 듣지 못하는 구조와 연결되어 마이크가 안 되면 게임 진행이 막힐 수 있기 때문이죠. 실행 오류나 튕김이 있다면 오래된 해결법을 무작정 따라가기보다 현재 버전부터 확인하시는 편이 좋습니다.

## 1. 최신 버전으로 업데이트한다

문제가 생기면 가장 먼저 스팀 라이브러리에서 봄바나나 업데이트가 남아 있는지 확인하시면 됩니다. 자동 업데이트가 꺼져 있거나 다운로드가 멈춰 있으면 이전 버전으로 실행될 수 있죠.

세 명이 함께 플레이하는 게임인 만큼 친구 세 명 모두 최신 상태를 맞추는 편이 좋습니다. 출시 초기에는 짧은 간격으로 수정 패치가 나오기 때문에 예전 버전에서 생긴 문제를 다른 방법으로 해결하려고 하면 시간을 낭비할 수 있습니다. 컨트롤러에서 UI가 보이지 않는 문제도 1점0점2에서 수정됐으니 같은 증상이 있다면 버전부터 확인하시기 바랍니다.

## 2. 스팀 재시작과 파일 무결성 검사

업데이트가 적용됐는데도 로비나 매치메이킹이 이상하다면 스팀 클라이언트를 완전히 종료한 뒤 다시 실행해 보시면 됩니다. 게임만 껐다 켜는 것보다 스팀 자체를 재시작하는 편이 더 확실하고, 단순한 세션 문제는 이것만으로 풀리는 경우가 있죠.

실행 직후 튕기거나 특정 구간에서 반복적으로 종료된다면 스팀 파일 무결성 검사를 먼저 해볼 만합니다. 손상되거나 빠진 파일이 있으면 자동으로 다시 받아주고, 재설치보다 빠르고 부담이 적어 가장 먼저 시도하기 좋습니다. 업데이트 후에도 음성 문제가 남아 있다면 파일 검사가 해답인 경우도 있죠.

## 3. 음성 입력 장치와 스팀 설정 확인

목소리가 안 들리거나 안 나간다면 먼저 윈도우 소리 설정에서 기본 마이크가 실제 사용 중인 장치로 잡혀 있는지 확인하시면 됩니다. 웹캠 마이크나 모니터 장치가 기본으로 선택되어 있으면 게임에서 엉뚱한 입력을 받을 수 있죠. USB 헤드셋이나 블루투스 이어폰을 여러 개 연결했다면 게임이 다른 장치를 선택하는 경우도 있습니다.

윈도우가 정상이어도 스팀 음성 설정이 다른 장치를 가리키면 문제가 생길 수 있습니다. 스팀에서 입력 장치와 입력 음량을 확인하고 마이크 테스트가 정상인지 본 뒤 게임을 다시 실행하시는 편이 좋죠. 디스코드나 녹화 프로그램이 마이크를 잡고 있다면 잠시 종료해 보시면 충돌 여부를 확인할 수 있습니다.

## 4. 로비 테스트와 원인 분리

폭탄 해체가 시작된 뒤 마이크 문제를 발견하면 한 판을 그대로 버릴 수 있으므로 로비 단계에서 세 명이 서로 들리는지 먼저 확인하시는 편이 좋습니다. 역할 특성 때문에 게임 안에서는 일부 음성이 제한될 수 있는데, 특히 귀머거리 원숭이가 소리를 못 듣는 규칙과 실제 음성 채팅 오류를 혼동하지 않도록 주의해야 하죠.

음성만 문제라면 입력 장치와 스팀 설정부터 보고, 프로그램 전체가 종료된다면 파일과 백그라운드 앱 쪽을 먼저 보는 것이 좋습니다. 마이크가 안 되는 문제와 게임 자체가 튕기는 문제는 원인이 다른 경우가 많죠.

## 5. 백그라운드 앱과 외부 음성 관리

방송 프로그램, 여러 오버레이, 가상 오디오 프로그램을 동시에 쓰면 게임이나 음성 장치와 충돌할 수 있습니다. 스팀 오버레이, 녹화 프로그램, 모니터링 도구를 많이 켜두었다면 잠시 줄여보시는 편이 좋죠. 저사양 PC에서는 메모리 여유가 줄면서 멀티플레이 중 끊김이나 튕김이 더 쉽게 나타납니다.

친구끼리만 플레이하는 상황이라면 게임 내 음성이 계속 불안정할 때 디스코드 같은 외부 음성 프로그램을 임시로 쓸 수 있습니다. 다만 봄바나나는 역할별 감각 제한이 게임 설계의 일부라서 외부 음성을 쓰면 원래 의도와 다른 상황이 생기죠. 문제 해결용으로만 사용하고 가능하면 게임 내 음성을 정상화한 뒤 플레이하시는 편이 좋습니다.

## 6. 재현 조건과 패치 흐름을 확인한다

계속 같은 순간에 튕긴다면 어느 로비, 어느 역할, 어느 스테이지에서 재현되는지 메모해 두시면 됩니다. 특정 모드에서만 문제가 생기는지, 특정 사람과 로비를 만들 때만 그런지, 게임 시작 직후인지 몇 판 뒤인지 기록해 감에 따라 원인 파악이 쉬워지죠. 호스트를 바꿔보거나 같은 조건을 다시 만들면 네트워크 문제인지 특정 상황 문제인지 구분하기 쉽습니다.

봄바나나는 출시 일주일 안에 두 번의 빠른 업데이트가 나왔고 개발진도 커뮤니티 피드백을 계속 추적한다고 밝혔습니다. 출시 초기 게임은 커뮤니티 해결법보다 공식 패치 흐름을 먼저 보는 것이 안전하죠. 큰 시스템 변경이나 보안 기능 해제처럼 위험한 방법을 따라 하기 전에 최신 수정 내역과 알려진 문제부터 확인하시기 바랍니다.
