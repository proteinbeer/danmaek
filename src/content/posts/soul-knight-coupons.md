## 2. 입력 방법

소울 나이트 쿠폰은 게임 시작 화면에서 입력합니다. 화면이 복잡해서 처음에는 입력창을 찾기 어렵지만 순서만 알면 간단합니다.

게임 실행 후 메인 화면 **좌측 하단의 톱니바퀴(설정) 아이콘**을 누릅니다. 설정 창 좌측 탭에서 **자물쇠 혹은 선물박스 아이콘**을 선택하면 쿠폰 입력창이 열립니다.

'선물 코드를 입력하세요' 입력란에 쿠폰 코드를 넣고 체크 버튼을 누르면 즉시 보상이 지급됩니다. 코드는 대소문자를 정확히 맞춰야 하며, 복사 붙여넣기로 입력하면 오타를 피할 수 있죠.

입력했는데 반응이 없다면 이미 사용한 코드이거나 오타가 난 경우가 많습니다. 다른 코드로 다시 시도해 주시기 바랍니다.

## 3. 오래된 코드도 찾아보면

소울 나이트는 오프라인에서도 동작하는 게임이기 때문에 스마트폰 시간 설정을 활용하면 만료된 코드를 다시 입력할 수 있다는 팁이 있습니다.

게임 출시일인 2017년 2월 17일 전후로 기기 날짜를 바꾼 뒤 게임을 실행하면 만료됐던 과거 코드가 정상적으로 인식되는 경우가 많다고 알려져 있죠. 다만 기기 설정을 바꾸는 것은 다른 앱에도 영향을 주므로 주의해야 합니다.

이 방법으로 오래된 코드를 시도해볼 수 있습니다. 그래도 계정당 1회가 원칙이므로 같은 코드 재입력은 의미가 없습니다.

## 4. 코드는 정확히, 보상은 바로 수령
