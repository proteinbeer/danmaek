리버스 1999는 블루포치(Bluepoch)가 개발한 20세기 시간 역행 전략 RPG입니다. 1999년의 마지막 날, 폭풍우가 쏟아지면서 세계가 과거로 되감기고 주인공 버틴이 타임키퍼가 되어 시대별 마도학자들을 구출하는 이야기를 풀어갑니다. 한국에서는 하오플레이가 서비스를 맡고 있으며 풀 한국어 더빙을 지원합니다.

리버스 1999의 교환 코드는 업데이트와 공식 방송에서 꾸준히 나옵니다. 대부분 무기한이지만 애니 상영이나 주년 이벤트 코드는 유효 기간이 짧은 편이죠. 코드가 보이면 바로 입력하는 습관이 좋습니다.

## 3. 코드 입력 방법

리버스 1999는 게임 내 메뉴에서 바로 코드를 입력합니다. 간단하게 따라 하시면 됩니다.

1. 게임을 실행하고 메인 화면에 진입합니다.
2. 화면 왼쪽 하단의 ··· (메뉴) 아이콘을 누릅니다.
3. [설정]을 선택하고 [계정] 탭으로 이동합니다.
4. [교환 코드 보상] 항목의 [이동] 버튼을 누릅니다.
5. 코드를 붙여넣고 [확인]을 누르면 보상이 우편함으로 지급됩니다.

입력 후 보상이 바로 표시되지 않아도 게임 내 우편함에서 수령할 수 있습니다. 코드 앞뒤에 공백이 붙지 않도록 그대로 붙여넣는 편이 좋죠.

## 4. 계정당 1회 사용과 만료 코드 주의

리버스 1999 코드는 계정당 1회만 사용할 수 있으며, 이미 사용한 코드를 다시 입력하면 오류 안내가 나옵니다. 일부 코드는 잔여 수량 소진 시 조기 종료되기도 합니다.

과거에 공개된 2024~2025년 코드들(6THEPERFECTNUMBER, GREENLAKE, VERSIONUPDATE 등)은 전부 만료됐습니다. 구버전 목록을 참고해 입력하다가 오류가 나는 경우가 많으니 위 표의 현재 목록만 사용하시기 바랍니다.
