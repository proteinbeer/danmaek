## 컴퓨터가 갑자기 느려졌다면 포맷 전에 작업 관리자부터 확인하세요

며칠 전까지 빠르던 PC가 갑자기 느려졌다고 바로 Windows를 다시 설치할 필요는 없습니다. 프로그램 하나만 느린지, 부팅부터 전체적으로 느린지, 게임을 실행했을 때만 끊기는지에 따라 확인할 곳이 달라집니다.

## Ctrl + Shift + Esc로 범인을 찾습니다

Ctrl + Shift + Esc를 눌러 작업 관리자를 열고 프로세스 탭에서 CPU, 메모리, 디스크 사용량을 각각 정렬합니다.

아무 작업도 하지 않는데 특정 프로그램이 CPU를 계속 많이 사용하거나 메모리를 비정상적으로 차지한다면 해당 프로그램을 확인합니다. 디스크 사용률이 계속 높다면 어떤 프로세스가 읽기·쓰기를 발생시키는지도 봅니다.

'90%면 무조건 고장'처럼 판단할 필요는 없습니다. 게임이나 압축 작업처럼 원래 자원을 많이 쓰는 상황도 있습니다. PC가 느려지는 순간 어떤 프로세스의 사용량이 함께 올라가는지가 중요합니다.

## 부팅 직후만 느리다면 시작 앱을 봅니다

Windows 로그인 후 몇 분 동안만 버벅인다면 작업 관리자의 시작 앱을 확인합니다. 메신저, 게임 런처, 클라우드 동기화 프로그램 등 매번 자동 실행할 필요가 없는 항목을 비활성화할 수 있습니다.

역할을 모르는 시스템 항목까지 무작정 끄지 말고 자신이 설치했고 용도를 아는 앱부터 정리합니다. 변경 후 재부팅하면 이전 상태와 비교하기 쉽습니다.

## C 드라이브도 확인합니다

설정 → 시스템 → 저장소에서 시스템 드라이브의 남은 공간을 확인합니다. 여유 공간이 매우 적으면 업데이트와 프로그램 작업에 불편이 생길 수 있습니다.

임시 파일과 사용하지 않는 대용량 앱을 확인하되 Windows 폴더의 파일을 직접 골라 삭제하지 않습니다.

## 느려진 시점에 백그라운드 작업이 있었는지 봅니다

Windows Update, 게임 다운로드, 클라우드 동기화와 백신 검사는 CPU·디스크·네트워크를 사용할 수 있습니다. 작업 관리자에서 실제 사용량을 확인한 뒤 판단합니다. 업데이트가 진행 중이라는 이유만으로 서비스를 강제로 끄기보다 작업이 끝난 뒤 원래 성능으로 돌아오는지 비교합니다.

## 재부팅 직후부터 계속 느리다면

소프트웨어 사용량에서 원인을 찾지 못했다면 온도와 저장장치로 범위를 넓힙니다. CPU나 GPU 온도가 지나치게 높아지면 보호를 위해 성능이 낮아질 수 있으므로 팬과 통풍 상태를 확인합니다.

저장장치 오류가 의심된다면 중요한 자료부터 백업합니다. SSD나 HDD에서 오류 징후가 있는데 테스트와 복구 작업을 반복하기보다 데이터 보존을 먼저 생각하는 편이 안전합니다.

특정 앱만 느리다면 PC 전체 문제로 보지 않습니다. 다른 프로그램과 Windows는 정상인데 한 앱만 느리다면 해당 앱의 확장 기능, 업데이트, 파일 손상이나 설정을 먼저 확인합니다.

포맷은 악성코드나 시스템 손상이 해결되지 않고 필요한 데이터 백업을 마쳤으며 일반적인 복구 방법으로도 Windows 자체 문제가 계속될 때 검토할 수 있습니다. 갑작스러운 속도 저하의 첫 단계는 아닙니다.
