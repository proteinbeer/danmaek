## 1. 내 파일 유지

내 파일 유지를 고르면 윈도우를 다시 설치하면서 문서, 사진 같은 개인 파일만 남깁니다. 대신 설치한 앱과 윈도우 설정은 제거되죠.

개인 파일이 남는다고 해도 중요한 자료는 별도로 백업해두시는 편이 안전합니다.

## 2. 모든 항목 제거

모든 항목 제거는 개인 파일, 앱, 설정까지 모두 지우고 윈도우를 다시 설치하는 방식입니다. 컴퓨터를 판매하거나 다른 사람에게 넘길 예정이라면 이쪽이 더 확실하죠.

드라이브 정리 옵션까지 사용하면 시간은 더 걸리지만, 삭제한 파일을 복구하기 어렵게 만드는 데 도움이 됩니다.

## 3. 클라우드 다운로드와 로컬 재설치

클라우드 다운로드는 마이크로소프트 서버에서 새 윈도우 설치 파일을 받아 쓰는 방식입니다. 현재 컴퓨터의 설치 파일이 손상됐다고 의심될 때 유용하죠.

로컬 재설치는 컴퓨터에 저장된 파일을 그대로 이용하는 것이라 인터넷이 느릴 때 편한데, 설치 파일 자체에 문제가 있다면 클라우드 다운로드가 더 나을 수도 있습니다.

## 4. 시작 전에 꼭 확인할 것

중요한 파일은 외장 저장장치나 클라우드에 먼저 백업해두세요. 장치 암호화를 사용 중이라면 비트로커 복구 키도 확인해두셔야 합니다.

초기화가 진행되는 동안 화면이 한동안 검게 남거나 여러 번 재부팅될 수 있고, 이때 전원을 강제로 끄면 실패할 수 있으니 끝까지 기다리시는 것이 좋습니다.
