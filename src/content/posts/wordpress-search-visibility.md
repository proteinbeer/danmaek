워드프레스 글을 계속 발행하는데 검색엔진에서 새 글이 거의 잡히지 않거나 사이트 전체 노출이 갑자기 줄어든 것처럼 느껴질 수 있습니다.

SEO 플러그인부터 바꾸기 전에 워드프레스 읽기 설정에서 검색엔진 노출을 막는 항목이 켜져 있지 않은지 먼저 확인할 필요가 있습니다.

사이트를 만들 때 임시로 검색 노출을 막아두었다가 정식 공개 뒤에도 그대로 두는 실수가 생각보다 자주 생깁니다. 설정 하나가 모든 검색엔진을 완벽하게 차단한다고 볼 수는 없지만 사이트가 노출을 원하지 않는다는 신호를 줄 수 있죠.

## 1. 읽기 설정부터 확인

관리자 화면의 설정, 읽기에서 검색엔진이 사이트를 색인하지 않도록 요청하는 항목을 확인하시면 됩니다.

정식 운영 사이트라면 이 옵션이 의도와 다르게 켜져 있지 않은지 먼저 보는 편이 좋습니다.

스테이징 사이트에서는 반대로 검색 노출을 막는 것이 필요할 수 있죠. 운영 사이트와 테스트 사이트의 설정을 복사하는 과정에서 값이 뒤섞이지 않게 구분하셔야 합니다.

## 2. 새 사이트라면 바로 노출되지 않을 수 있다

설정이 정상이라고 새 글이 즉시 검색 결과에 나타나는 것은 아닙니다.

검색엔진이 사이트를 발견하고 방문해 내용을 읽고 색인하는 과정에는 시간이 필요합니다.

새 도메인이나 글이 적은 사이트는 검색엔진이 자주 방문하지 않을 수 있죠. 이때 하루 이틀 노출이 없다고 설정을 계속 바꾸면 오히려 원인을 판단하기 어려워집니다.

## 3. 사이트맵이 열리는지도 확인

워드프레스는 기본적으로 사이트맵 기능을 제공하며 SEO 플러그인을 사용하면 별도 사이트맵을 생성하기도 합니다.

사이트맵 주소가 정상적으로 열리고 최근 글이 포함돼 있는지 확인하시면 검색엔진이 사이트 구조를 읽을 수 있는지 보는 데 도움이 됩니다.

사이트맵을 두 개 이상 만들었다고 검색 노출이 두 배가 되는 것은 아닙니다. 기본 기능과 플러그인 기능이 중복된다면 어느 쪽을 사용할지 명확히 정하는 편이 관리하기 쉽죠.

## 4. 글 자체가 비공개인지 확인

검색 노출 문제처럼 보여도 실제 글 상태가 초안, 비공개, 비밀번호 보호로 남아 있는 경우가 있습니다.

관리자 글 목록에서 해당 게시물이 공개 상태인지 먼저 확인하시면 됩니다.

카테고리와 태그 페이지는 플러그인 설정에 따라 색인을 막도록 구성할 수도 있죠. 사이트 전체와 특정 글, 특정 목록 페이지를 구분해야 어느 설정을 봐야 할지 명확해집니다.

## 5. SEO 플러그인의 개별 설정

SEO 플러그인을 사용한다면 글마다 검색엔진 노출 허용 여부를 따로 설정할 수 있는 경우가 있습니다.

전체 사이트 설정은 정상인데 특정 글만 검색되지 않는다면 해당 글의 로봇 설정과 대표 주소 설정을 확인해보시면 됩니다.

플러그인을 두 개 이상 겹쳐 쓰면 서로 다른 신호를 만들 수 있죠. 검색 최적화 기능은 한 플러그인이나 한 설정 체계로 단순하게 관리하는 편이 좋습니다.

## 6. 주소를 자주 바꾸면 다시 기다려야 한다

글 제목과 함께 주소까지 자주 변경하면 검색엔진이 기존 주소와 새 주소를 다시 연결해야 합니다.

고유주소를 바꿨다면 기존 주소에서 새 주소로 적절히 이동되도록 처리하는 것이 중요하죠.

검색이 안 된다고 주소를 반복해서 바꾸는 방식은 오히려 안정적인 색인을 방해할 수 있습니다. 공개 뒤에는 주소를 가능한 한 유지하는 편이 관리하기 쉽습니다.

## 7. 검색 도구에서 실제 상태 확인

검색엔진이 제공하는 사이트 관리 도구를 사용하시면 특정 주소가 색인됐는지, 접근이 막혔는지 확인할 수 있죠.

검색 결과에서 직접 사이트 이름만 반복해서 찾는 것보다 훨씬 정확한 상태를 볼 수 있습니다.

오류가 표시된다면 문구를 기준으로 원인을 해결하시면 됩니다. 발견되지 않은 것과 발견했지만 색인하지 않은 것은 대응이 다르기 때문에 상태를 구분하는 것이 중요하죠.

## 8. 노출 문제는 글 수보다 접근 가능 여부부터

저는 검색 노출이 줄었다고 느껴질 때 새 글을 더 쓰기 전에 검색엔진이 사이트에 들어올 수 있는 상태인지부터 확인하는 편이 맞다고 봅니다.

아무리 좋은 글이 많아도 사이트가 스스로 들어오지 말라고 신호를 보내고 있다면 먼저 그 문제를 풀어야 합니다.

읽기 설정, 글 공개 상태, 사이트맵, SEO 플러그인, 주소 변경 순서로 확인하시면 됩니다. 검색 노출은 콘텐츠 문제일 수도 있지만 기술 설정 하나에서 막히는 경우도 충분히 있죠.
