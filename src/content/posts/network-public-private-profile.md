## 윈도우 공용 네트워크와 개인 네트워크, 무엇을 선택해야 할까

윈도우에서 와이파이나 이더넷에 연결하면 공용 또는 개인 네트워크 프로필을 사용할 수 있습니다. 이름만 보면 개인 네트워크가 개인정보 보호에 더 유리해 보이지만 실제 선택 기준은 지금 연결한 네트워크 안의 다른 기기를 신뢰할 수 있는지입니다.

## 집에서는 왜 개인 네트워크를 사용할까

자신이 관리하는 공유기에 PC, NAS, 프린터를 연결해 사용하는 환경이라면 개인 네트워크가 적합할 수 있습니다. 개인 프로필에서는 같은 내부망의 장치를 찾는 네트워크 검색과 파일·프린터 공유 기능을 사용하기 쉽습니다.

집의 두 PC가 같은 공유기에 있는데 탐색기의 네트워크 목록에서 서로 보이지 않는다면 양쪽의 네트워크 프로필을 확인할 필요가 있습니다. 한쪽이 공용이면 네트워크 검색 관련 방화벽 규칙 때문에 검색이 제한될 수 있습니다.

다만 개인으로 바꾼다고 폴더와 파일이 자동으로 모두 공개되는 것은 아닙니다. 실제 공유 여부는 공유 설정, 사용자 권한과 Windows 방화벽 규칙의 영향을 별도로 받습니다.

## 카페와 호텔에서는 공용을 유지합니다

공항, 카페, 호텔처럼 누가 같은 네트워크를 사용하는지 알 수 없는 장소에서는 공용 프로필을 유지하는 편이 좋습니다. 공용 프로필은 같은 네트워크의 다른 기기에서 내 PC를 발견하거나 접근할 수 있는 범위를 제한하는 방향으로 사용됩니다.

공공 와이파이에서 인터넷 접속에 문제가 있다는 이유로 개인으로 바꾸는 것은 해결책이 아닙니다. 와이파이 인증, IP 주소, DNS 또는 시설의 로그인 페이지 문제는 따로 확인해야 합니다.

## 현재 설정 확인

Windows 11에서는 설정 → 네트워크 및 인터넷에서 현재 Wi-Fi 또는 이더넷 연결의 속성을 열어 네트워크 프로필 유형을 확인할 수 있습니다.

자신이 관리하는 집 네트워크이고 로컬 장치 검색이나 공유가 필요하다면 개인을 선택할 수 있습니다. 불특정 사용자가 연결하는 네트워크라면 공용을 유지합니다. 회사에서 관리하는 PC는 조직 정책을 우선합니다.

## 개인으로 바꿨는데도 다른 PC가 안 보인다면

프로필은 장치 검색 문제의 한 조건일 뿐입니다. 개인으로 변경했는데도 PC가 보이지 않는다면 상대 PC의 IP 주소로 직접 접근할 수 있는지 확인할 수 있습니다.

상대 PC 주소가 192.168.0.30이라면 파일 탐색기 주소창에 \\192.168.0.30을 입력합니다. 직접 접근은 되는데 네트워크 목록에만 없다면 네트워크 검색 기능 쪽으로 범위를 좁힐 수 있습니다. 직접 접근도 안 된다면 파일 공유 설정, 방화벽, 사용자 권한과 두 PC가 실제 같은 로컬 네트워크에 있는지 확인합니다.

## 공용과 개인은 인터넷 속도 설정이 아닙니다

개인으로 바꾼다고 다운로드 속도나 Wi-Fi 신호가 좋아지지는 않습니다. DNS나 공유기의 NAT 방식도 바뀌지 않습니다.

선택 기준은 간단합니다. 내가 관리하고 신뢰하는 내부망에서 다른 장치와 통신해야 한다면 개인을 검토하고, 구성원을 알 수 없는 네트워크라면 공용을 사용합니다. 이름보다 '같은 네트워크의 다른 장치를 신뢰할 수 있는가'를 기준으로 보면 헷갈리지 않습니다.
