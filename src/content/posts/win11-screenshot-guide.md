에러 메시지를 물어보거나 게임 기록을 남길 때, 스크린샷은 가장 확실한 방법입니다. 윈도우 11에는 별도 프로그램 없이 바로 쓸 수 있는 캡처 기능이 내장되어 있죠.

부분 캡처부터 전체 화면 저장까지, 단축키 몇 개만 알아두면 어떤 상황에서도 화면을 바로 남길 수 있습니다. 윈도우 11 스크린샷 방법을 정리했습니다.

## 1. 가장 빠른 부분 캡처, Win+Shift+S

원하는 부분만 잘라서 캡처하고 싶다면 **Windows + Shift + S**가 정답입니다.

- 키를 누르면 화면 상단에 캡처 도구 모음이 나타납니다.
- **사각형 모드, 자유형 모드, 창 모드, 전체 화면 모드** 중 하나를 선택합니다.
- 원하는 영역을 드래그하면 클립보드에 저장되고, 우측 하단에 미리보기가 잠깐 표시됩니다.

캡처 후에는 **Ctrl + V**로 문서나 채팅창에 바로 붙여넣을 수 있습니다. 저장까지 필요한 경우 미리보기 창에서 저장 버튼을 눌러 파일로 남기면 됩니다.

## 2. 전체 화면을 파일로 저장, Win+PrintScreen

화면 전체를 파일로 바로 저장하고 싶다면 **Windows + Print Screen**을 누릅니다.

- 누르는 순간 화면이 살짝 어두워지며 전체 화면이 저장됩니다.
- 파일은 **사진(Pictures) 폴더의 스크린샷(Screenshots) 폴더**에 자동으로 쌓입니다.
- 단축키를 쓰지 않아도 **Print Screen** 키만 누르면 클립보드에 전체 화면이 복사됩니다.

저장 위치를 자주 쓰는 곳이 있다면 탐색기에서 스크린샷 폴더를 즐겨찾기에 추가해 두면 편리합니다.

## 3. 캡처 도구 앱 활용하기

캡처 후 편집과 공유까지 한 번에 처리하려면 **캡처 도구(Snipping Tool)** 앱을 엽니다.

- 시작 메뉴 검색에서 **캡처 도구**를 입력해 실행합니다.
- **새로 만들기** 버튼으로 여러 모드의 캡처가 가능하고, 캡처한 이미지를 바로 펜·하이라이터로 편집할 수 있습니다.
- 지연 캡처 옵션을 3초나 10초로 설정하면 메뉴가 열린 화면도 잡을 수 있습니다.

캡처 도구는 **Windows 11 22H2 이상**에서 화면 녹화와 텍스트 인식(OCR) 기능도 지원합니다. 이미지 안의 글자를 복사하고 싶을 때 특히 유용하죠.

## 4. PrintScreen 키 동작 바꾸기

PrintScreen 키의 기본 동작(클립보드 복사)을 캡처 도구가 열리도록 바꿀 수도 있습니다.

- **설정 → 접근성 → 키보드**로 이동합니다.
- **인쇄 화면 바로 가기 사용** 항목을 켭니다.
- 이후 **Print Screen** 키를 누르면 캡처 도구가 바로 열립니다.

이 설정을 켜두면 특정 영역 캡처를 자주 하는 분에게 훨씬 편리합니다. Win+Shift+S와 동일한 동작을 PrintScreen 하나로 처리할 수 있죠.

## 5. 캡처 파일 찾기와 관리

스크린샷이 많은 분은 저장 폴더 정리를 해두면 나중에 찾기 쉽습니다.

- 전체 화면 저장이 쌓이는 **사진 → 스크린샷** 폴더를 시작 메뉴에 고정하거나 별도 폴더로 이동합니다.
- 캡처 도구로 저장한 파일은 이름에 **캡처(날짜)** 형식이 붙습니다.
- 공유할 때는 파일 크기가 작은 부분 캡처가 유리하고, 이미지 압축이 필요하면 캡처 도구에서 바로 올릴 수 있습니다.

에러 로그와 비교용 스크린샷은 날짜 순으로 정리되므로, 폴더명에 용도를 붙여 분류하면 나중에 효율적입니다.

## 6. 게임 속 화면과 스크린샷 팁

게임 중 화면을 남기고 싶다면 게임 바(Game Bar)의 캡처 기능을 쓰는 것도 방법입니다.

- **Windows + Alt + Print Screen**을 누르면 게임 화면이 바로 저장됩니다.
- 게임 바 스크린샷은 기본적으로 **동영상 폴더의 캡처(Captures) 폴더**에 저장됩니다.
- 전체 화면 게임에서는 일부 게임이 자체 스크린샷 기능(키)을 제공하기도 하므로, 둘 중 편한 쪽을 쓰시면 됩니다.

게임 바 캡처 화질은 **설정 → 게임 → 캡처**에서 조절할 수 있습니다. 스크린샷을 자주 찍는 게임이라면 저장 형식과 화질을 미리 정해두면 좋습니다.
