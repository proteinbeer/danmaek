## 3. 코드 입력 방법

쿠키런: 모험의 탑은 게임 내가 아니라 공식 쿠폰 페이지에서 코드를 입력하는 방식입니다. DevPlay 계정을 쓰는 만큼 연동 상태를 먼저 확인하십시오.

1. 게임 실행 후 상단 햄버거 메뉴(≡)를 누릅니다.
2. [설정] → [계정] 탭에서 DevPlay 계정 이메일(MID)을 확인합니다.
3. 공식 쿠폰 페이지(coupon.devplay.com/coupon/cookieruntoa/ko)에 접속합니다.
4. DevPlay 계정 이메일을 입력하고 쿠폰 코드를 붙여넣습니다.
5. [상품 받기]를 누르고, 게임을 재시작한 뒤 우편함에서 보상을 수령합니다.

## 4. 계정당 1회 사용과 만료 코드 주의

쿠키런: 모험의 탑 쿠폰은 계정당 1회만 사용할 수 있으며, 대소문자를 정확히 구분해 입력해야 합니다. 이미 사용한 코드나 만료된 코드를 입력하면 "사용할 수 없는 쿠폰" 안내가 나옵니다.
