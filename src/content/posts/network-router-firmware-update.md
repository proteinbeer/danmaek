공유기는 한 번 설치하면 몇 년 동안 설정 화면에 들어가지 않는 장비가 되기 쉽습니다. 하지만 집 안 모든 기기의 인터넷이 지나가는 장비라 보안 취약점과 안정성 문제가 발견되면 펌웨어 업데이트가 중요한 유지 관리가 됩니다.

업데이트는 속도를 무조건 올리는 작업이 아닙니다. 특정 와이파이 끊김과 호환성 오류, 보안 문제를 수정하는 경우가 많아 오래된 공유기일수록 현재 버전과 지원 상태를 한 번 확인할 가치가 있습니다.

1. 현재 버전부터 기록

공유기 관리 화면에서 모델명과 펌웨어 버전을 확인하고 제조사 공식 지원 페이지의 최신 버전과 비교합니다. 비슷한 모델명이 많으므로 하드웨어 버전까지 구분해야 잘못된 파일을 올리는 실수를 줄일 수 있습니다.

자동 업데이트 기능이 있는 제품은 실제로 적용됐는지도 확인합니다. 자동이라는 이름이 있어도 중요 업데이트만 적용하거나 재부팅 시간 때문에 설치가 대기 중인 경우가 있습니다.

2. 업데이트 전 설정 백업

공유기마다 설정 백업 기능이 있다면 업데이트 전에 현재 구성을 저장해두는 편이 좋습니다. 포트포워딩과 DHCP 예약, 와이파이 이름처럼 다시 만들기 번거로운 설정이 많다면 특히 유용합니다.

오래된 설정 파일을 다른 모델이나 큰 버전 차이가 있는 펌웨어에 무조건 복원하는 것은 피하는 편이 좋습니다. 제조사가 호환을 보장하는 범위 안에서만 사용해야 합니다.

3. 업데이트 중 전원 차단 금지

펌웨어를 쓰는 도중 전원이 끊기면 공유기가 정상 부팅하지 못할 수 있습니다. 가능하면 안정적인 전원 환경에서 진행하고 업데이트가 끝날 때까지 전원 버튼과 케이블을 건드리지 않습니다.

무선으로 관리 화면에 들어갈 수는 있지만 제조사가 유선 업데이트를 권장한다면 랜선으로 연결하는 편이 더 안전합니다. 작업 중 와이파이가 잠시 끊기는 것은 정상일 수 있습니다.

4. 업데이트 뒤 확인

업데이트가 끝나면 인터넷 연결만 확인하고 끝내지 말고 2.4GHz와 5GHz, 포트포워딩, 예약 주소처럼 실제 사용하는 기능을 간단히 점검합니다. 큰 업데이트에서는 메뉴 위치나 기본값이 달라지는 경우도 있습니다.

이전에는 잘 되던 구형 IoT 장치가 갑자기 연결되지 않는다면 보안 방식이 강화됐는지도 확인합니다. 문제가 생겼다고 바로 구버전으로 내리기보다 변경된 설정을 먼저 보는 편이 좋습니다.

제조사가 더 이상 보안 업데이트를 제공하지 않는 장비라면 펌웨어를 최신으로 만드는 데도 한계가 있습니다. 특히 인터넷에 직접 연결되는 오래된 공유기는 단순히 느리다는 이유보다 보안 지원 종료 때문에 교체를 고려할 수 있습니다.

공유기는 PC와 스마트폰보다 더 오래 켜져 있는 장비입니다. 몇 달마다 새 버전을 찾을 필요까지는 없더라도 모델 지원 상태와 자동 업데이트 여부 정도는 주기적으로 확인하는 편이 안전합니다.

업데이트 뒤 며칠 동안 재부팅과 끊김이 사라졌다면 펌웨어 수정이 실제 원인이었을 가능성을 높게 볼 수 있습니다. 반대로 증상이 그대로라면 회선과 무선 환경을 따로 점검해 펌웨어만 반복 설치하지 않는 편이 좋습니다.

공유기 펌웨어는 눈에 보이는 새 기능보다 보안과 안정성 때문에 더 중요할 때가 많습니다. 오래 쓰는 장비일수록 지원이 계속되는지 확인하는 것 자체가 유지 관리의 한 부분입니다.

자동 업데이트를 켜두셨다면 업데이트가 적용되는 시간에 잠깐 인터넷이 끊길 수 있다는 점도 알아두시면 됩니다. 가족이 온라인 게임이나 화상회의를 하는 시간과 겹치지 않도록 재부팅 시간을 지정할 수 있는 제품이라면 활용할 만합니다.
