공유기는 스마트폰처럼 매일 화면을 보는 장비가 아니라 설치한 뒤 몇 년 동안 같은 상태로 쓰기 쉽습니다. 하지만 집 안 기기와 인터넷 사이에 계속 연결되어 있으므로 펌웨어 지원 여부는 생각보다 중요합니다.

펌웨어 업데이트의 목적은 단순히 새 기능을 추가하는 것만이 아닙니다. 제조사가 발견된 보안 문제를 수정하거나 연결 안정성, 특정 기기와의 호환성 문제를 고치는 데도 사용됩니다.

## 먼저 모델명과 현재 버전을 기록합니다

업데이트 버튼부터 누르기 전에 공유기의 정확한 모델명과 하드웨어 버전을 확인합니다.

같은 제품명처럼 보여도 하드웨어 리비전에 따라 사용하는 펌웨어 파일이 다를 수 있습니다. 수동 업데이트 파일을 받을 때는 제조사의 공식 지원 페이지에서 자신의 모델과 하드웨어 버전에 맞는 파일인지 확인해야 합니다.

관리 페이지에서는 현재 설치된 펌웨어 버전도 함께 기록해둡니다.

## 자동 업데이트가 있다면 확인할 것이 줄어듭니다

최근 공유기 중에는 새 정식 펌웨어를 자동으로 설치하거나 업데이트가 있을 때 알림을 제공하는 제품이 있습니다.

자동 업데이트를 지원한다면 기능이 활성화되어 있는지 확인합니다. 다만 제조사가 제공하는 베타 펌웨어를 ‘숫자가 더 높다’는 이유만으로 설치할 필요는 없습니다. 특별한 문제 해결 목적이 없다면 일반 사용자는 정식 배포 버전을 우선하는 편이 안정적입니다.

## 수동 업데이트 전에는 설정 백업 여부를 확인합니다

공유기가 설정 내보내기 기능을 제공한다면 현재 설정을 백업해둘 수 있습니다.

업데이트 중에는 장비 전원을 끄거나 전원 케이블을 뽑지 않습니다. 가능하다면 업데이트 작업을 하는 PC는 와이파이보다 유선으로 연결하는 편이 안정적입니다.

업데이트가 끝난 뒤에는 펌웨어 버전이 실제로 바뀌었는지 확인합니다. 무조건 공장 초기화를 할 필요는 없지만 제조사가 특정 업데이트에서 초기화를 요구했다면 해당 안내를 따릅니다.

## 업데이트하면 인터넷이 빨라질까

펌웨어 업데이트는 인터넷 요금제의 속도를 높이는 기능이 아닙니다.

다만 기존 펌웨어에 와이파이 호환성 문제, 연결 끊김, 메모리 관련 오류 등이 있었고 새 버전에서 해당 문제가 수정됐다면 체감 안정성이 좋아질 수 있습니다.

반대로 아무 문제가 없는 환경에서 펌웨어를 업데이트했다고 다운로드 속도가 갑자기 두 배가 되는 것을 기대할 이유는 없습니다.

## 더 중요한 것은 ‘마지막 업데이트가 언제였는가’입니다

공유기가 오래됐다는 사실만으로 바로 위험하다고 단정할 수는 없습니다. 더 중요한 것은 제조사가 해당 모델을 아직 지원하는지입니다.

공식 지원 페이지에서 펌웨어가 수년간 업데이트되지 않았고 제품이 지원 종료(EOL) 상태라면 앞으로 발견되는 보안 문제에 대한 수정도 기대하기 어려울 수 있습니다.

이때는 단순히 ‘아직 인터넷이 되니까 계속 쓴다’보다 교체 시점을 검토할 이유가 생깁니다.

## 교체를 고려할 신호

- 제조사가 지원 종료를 명시했습니다.

- 알려진 보안 문제에 대한 수정 펌웨어가 제공되지 않습니다.

- 현재 사용하는 인터넷 속도나 와이파이 규격을 장비가 지원하지 못합니다.

- 재부팅해도 반복되는 연결 불안정이 있고 최신 정식 펌웨어에서도 해결되지 않습니다.

이런 조건이 겹친다면 설정을 계속 만지는 것보다 새 장비가 현실적인 해결책일 수 있습니다.

공유기 펌웨어는 ‘문제가 생겼을 때만 한 번 업데이트하는 것’보다 현재 장비가 계속 보안 지원을 받고 있는지를 확인하는 관리 항목에 가깝습니다. 정확한 모델을 확인하고 제조사의 공식 지원 페이지에서 정식 버전과 지원 상태를 보는 것부터 시작하면 됩니다.
